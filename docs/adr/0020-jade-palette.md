# 以青绿为主的五色体系

- 日期 2026-11-24，状态已采纳。
- 色板由用户指定，主色 `#169873`，辅助色 `#805D93`、`#F49FBC`、`#FFD3BA`、`#9EBD6E`。延续 ADR 0019 的布局与材质规则，以本 ADR 为当前取色依据。[Coolors 色板](https://coolors.co/palette/805d93-f49fbc-ffd3ba-9ebd6e-169873)

## 决定

1. 常规页面的主要动作、焦点与选中态属于青绿品牌家族。主按钮直接使用原色，配深墨色字形。文本链接、图表和控件按所在底面取相应对比度档。
2. 六个数据域保留各自的语义。行程与里程取主青绿，补能取青绿的偏蓝衍生色，能效取橄榄绿，费用取桃，环境取粉，停放／时长取紫。同一域跨页复用色阶。并列图表依靠图例、指标名称和位置辅助区分。
3. 混合数据组用低彩度中性色面，单域普通卡和专题入口共用同一层叠色，主读数使用更强叠色。辅助色的原值作为色阶锚点，大面积卡面使用叠色，文字按对比度选取明度。警示与错误语义保持独立。
4. 底部 Tab Bar 保留原选中颜色、交互反馈及玻璃渲染参数。材质光学、组件几何和动效继续沿用 ADR 0019。

色值分档、页面关系与验收见 [VH19–VH22](../specs/visual-hierarchy.md#10-青绿五色体系)。
