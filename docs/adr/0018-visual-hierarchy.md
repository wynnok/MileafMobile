# 让首屏主读数承担视觉重心

- 日期 2026-11-24，状态 **配色与控件玻璃已实现，其余为提案**。此切片在 [ADR 0017](0017-chromatic-intensity.md) 上修订主读数、记录和专题入口用色及非底栏材质。
- 内容卡、专题入口与浮动选择器的现行规则见 [ADR 0019](0019-content-surfaces.md)。以下保留该轮实施依据。
- 用户反馈上一版样张过暗、色彩不够明亮活泼、控件缺少玻璃质感。新版本将截图的主次反差和悬浮层次落实在行笺的数据任务上，浅色用亮色焦点与高对比墨字，深色适度加亮域色。[方案与规格](../specs/visual-hierarchy.md) · [实施票据](../specs/visual-hierarchy-tickets.md) · [核验记录](../implementation/visual-hierarchy-plan.md)

## 背景

Days Matter 用一个优先读数、低密度分组和按场景出现的磨砂层加速扫读。行笺每页需要额外回答数据属于哪台车、哪个期间、采用什么口径以及证据在哪里。ADR 0017 已建立六数据域与亮面资源，但主读数和同域普通卡仍常共用 24%／22% 的洗色层，深色统计入口也会回落到这一级。视觉重心可以更集中，同时给文字留出足够的对比余量。

## 配色实施与其余提议

1. 数据页以一个主读数承担焦点。六个行笺亮面原料浅色 48% 合在白底，深色 32% 合在石板底，搭配高对比中性文字。概览优先车况，行程优先里程，充电优先已记录费用，统计优先结论。记录和绘图区用中性表面，专题入口调为浅 32%／深 24%。见 VH01–VH04。
2. 设置、站点与会话以任务层级和既有动作蓝建立焦点。组件继续使用行笺图标族、4pt 栅格和既有的读数层级，补齐各页图标映射、卡间距、图表降级与状态反馈。见 VH05–VH09。
3. 统一非底栏控件玻璃。滚动顶栏、两种锚定菜单、地图浮控和概览电量仪表共用 σ22、1.5 倍饱和度、90% 中性叠色与实色回退。顶栏按钮和期间选中层用同款镜片边缘，免叠加背景滤镜。原生地图以对应平台合成验证为前提。弹层保持实色，内容与图表落平涂。见 VH10–VH11。
4. 使用现有反馈和状态转换时长，逐入口补齐减少动态效果、焦点和在途更新的验收。底部 Tab Bar 的结构、样式、动效与共享渲染路径原样保留。见 VH12–VH14。
