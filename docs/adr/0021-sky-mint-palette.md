# 天蓝与薄荷配色

- 日期 2026-11-24，状态已采纳。取色接续 [ADR 0020](0020-jade-palette.md)，色面层级和材质沿用 [ADR 0019](0019-content-surfaces.md)。
- 用户确认了以 `#95CAEA`、`#9AF1CD`、`#0E7C7B`、`#F65A49`、`#4B1D3F` 为锚点的浅深两套样稿。[Coolors 色板](https://coolors.co/palette/f65a49-95caea-9af1cd-0e7c7b-4b1d3f)

## 决定

1. 行程及里程用天蓝，车况、电量及补能用薄荷，能耗与效率用深青。费用以珊瑚标记与浅珊瑚卡面链接账目和记录。时长、停放及环境共享梅紫家族，环境面更淡。缺失、警示和错误继续使用独立角色。
2. 每个数据域配对普通面、焦点面及读数前景。浅色用淡彩面积和深色字区分，深色将色相保留在较暗背板与发亮读数里。混合数据用低彩度的雾灰面。各域分别定两档实际背景，修正统一透明度导致的面积与饱和度失衡。
3. 主动作使用深青原色及白字。分段选中使用浅深青色镜片。图形和文字走各自的可读档，珊瑚原色等标记填色依靠独立描边或数据系列承载辨识。
4. 页面结构、组件尺寸、材质参数、动效以及底部 Tab Bar 的样式、按压反馈、偏好回退继续沿用。页面配色通过玻璃后，底栏能自然取样到新的页面内容。

精确值、逐页映射和验证见 [VH23–VH26](../specs/visual-hierarchy.md#11-天蓝与薄荷)。
