## 背景

用户要求整体优化交互、美感、内容布局、样式和动画，向 Apple 的克制、精致、一体性和秩序感看齐，并引入有明确用途的玻璃质感。当前阶段交付设计文档，产品实施已按用户确认的范围推进到本地交付。

当前代码已集成 U00–U12 及后续分段控件、二级导航对齐修正。旧规格首页的“实施待开始”属于 2026-11-12 发布时状态。当前本地交付事实见 [U12](../implementation/ui-ux-refinement/U12.md)。2026-11-14 只读查询显示 GitHub #27–#40 仍为 OPEN，工单状态另行记录。

现有共享 tokens、阅读上下文、可控 HTTP 测试和 Flutter 图册提供了可靠的迁移接缝。此次需要解决的呈现问题包括导航与内容缺少材质层次、概览深色块权重过大、页面标题与操作体系分散，以及按压、选中、弹层反馈尚未形成完整的连续语言。代码依据和图像来源见规格 §2。

## 提议决定

1. 将内容、导航、临时操作分为有明确职责的三个层级。正文与图表使用清晰的中性表面，浮动底栏和有内容经过的顶栏采用磨砂玻璃。弹层正文使用不透明表面。
2. 用更清晰的页面标题、收敛的主数字和更舒适的正文形成层级。保留电光蓝、Inter 与平台中文回退、现有图形语义和四个主目的地。
3. 概览采用与当前外观一致的车况表面。列表突出路线、地点与结果，详情突出地图与过程图，统计保持结论、主图、四专题的任务顺序。
4. 动效由用户操作触发。按压、选中移动、路由和弹层具有固定参数、打断规则及减动效路径，数据和选中状态即时正确。
5. 本轮建议使用 Flutter 的裁剪背景模糊、叠色、细边缘和受控阴影实现跨端磨砂玻璃。该实现具有独立的材质名称和参数表。Apple 原生 Liquid Glass 的折射、系统材质偏好联动属于后续原生渲染候选，需单独评估 Flutter 合成与地图兼容性。
6. 系统减少透明度、高对比、减少动效分别处理。iOS 减少透明度采用专用只读桥接，启动未知或桥接失败使用实色。地图平台视图区域采用实色操作控件。
7. 共享系统先收敛，代表页面再冻结，页面包随后并行。共享文件由单一所有者维护，每包有文件边界、输入提交和可复现证据。

Apple HIG 将 Liquid Glass 用于导航与控件层，并要求克制使用，强调材质上的可读性。iOS 27 官方介绍同样将可读性与对比列为改进方向。此处提取这些原则作为设计依据，本文的具体数值和跨端方案为行笺提案。[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[iOS 27](https://www.apple.com/os/ios/)

## 旧规则接续

用户确认后，以下增量进入实施。确认之前，ADR0011 及现有规格继续描述当前有效系统。

| 当前规则 | 拟采用的增量 |
| --- | --- |
| ADR0011 与旧规格 R02 的字阶 | 新规格 R12 的完整角色表 |
| 旧 R04 的概览深底、圆角、导航实色及模糊限制 | 新 R13–R14 的内容表面与导航材质白名单 |
| 旧 R05 的根页面顶栏、底栏、控件几何 | 新 R15 的统一导航与控件合同 |
| 旧 R07 的选中和反馈动效 | 新 R16 的动效表与打断合同 |
| 旧 P01–P16 中的呈现参数及旧 §5 预算 | 新规格 §4–§5 的逐页增量和测量口径 |
| ADR0006 中性底、电光蓝与默认跟随系统 | 沿其语义继续应用，新材质增加专用 token |

业务约束沿旧 S01–S08 与所有原始功能契约接续，迁移清单沿现有 capability-map。费用补录、认证、地图隐私、时间口径和阅读恢复仍按原合同验收。新规格逐项列明受保护的接缝。

## 取舍与影响

统一采用 Flutter 材质可以复用现有组件、语义和触控测试，代价是需自行验证背景合成、清晰度及模糊成本。2026-11-16 起，根级悬浮底栏按 [ADR 0013](0013-liquid-glass-navigation.md) 提升为 Flutter 合成的液态玻璃近似；顶栏仍为本文的磨砂材质，原生折射与系统材质联动继续留在候选。原生 Liquid Glass 可提供系统光学与设置联动，采用它需要额外的双端渲染和原生视图集成方案。现有 Flutter 框架和地图平台视图使这项成本值得独立评估。[Flutter 平台视图](https://docs.flutter.dev/platform-integration/ios/platform-views)

新增范围集中于设计组件、页面呈现与专用无障碍显示偏好桥接，桥接仅返回布尔显示偏好。产品依赖和后端能力沿冻结工具链。材质失败时使用同几何实色表面，布局、触控与正文保持可验证。
