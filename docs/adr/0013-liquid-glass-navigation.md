# 以液态玻璃重塑悬浮底栏

> 2026-11-16 接续说明：[ADR0014](0014-apple-polish.md)（当日已确认）保留本文全部材质、几何与对比决定，只修订 L09：底栏标签放大封顶 1.35×，以长按大内容查看器补足；在 AP02 实施并验收前 L09 继续有效。

- 日期为 2026-11-16，状态为 **accepted，已实施**（本地，未推送）。用户当日指令：「将应用底部的 bar 设计成 iOS 27 的液态玻璃风格，高透但不影响阅读」，并指定参考图 2 红框：悬浮胶囊、高透、选中项是一枚更亮的独立胶囊。
- 沿用[焕新规格](../specs/apple-design-renewal.md) R14–R15 的导航材质与几何合同，本 ADR 是其增量，只改**悬浮底栏**的材质与形状。顶栏磨砂、四个目的地与顺序、命中尺寸与阅读连续性都不变。
- 配套规格为[液态玻璃底栏规格](../specs/liquid-glass-navigation.md)，实施与实测见[实施记录](../implementation/liquid-glass-nav.md)。

## 背景

当前底栏材质是 88–90% 近不透明叠色 + 18σ 模糊 + 1px 边 + 单层阴影，形状是 28 圆角矩形。因为叠色接近实色、内容又被页面底部留白挡在栏外，磨砂几乎读不出「玻璃」。ADR 0012 已把 Apple 原生 Liquid Glass 的折射与系统材质联动列为**后续原生候选**；用户现在要求把底栏直接提升到液态玻璃观感，仍在 Flutter 合成层完成，不引入平台视图。

## 决定

1. **形状。** 浮栏改为胶囊（半径取高度一半），外距 16、下距安全区 8、视觉最小高 64、最大宽 528 全部沿用 R15；选中镜片同样是胶囊，外框内缩 4 / 6。
2. **材质。** 新增 `MileafGlassSurface`，四层静态光学，顺序固定：36σ 模糊 + 1.35 过饱和、上淡下浓的玻璃体叠色（浅色 40%→56% 白、深色 48%→63% 近黑）、顶部固定高光与下沿弯月、内外两圈受光边缘。没有扫光、没有动画光学参数，材质本身不变，只有位置随内容变化。
3. **高透下的可读。** 玻璃体只叠本模式的中性色，因此它只会把背后内容朝 canvas 方向推：浅色页只会更亮、深色页只会更暗，色相不参与。390×844 机位直接量取渲染像素（`contrast.json`，由渲染测试断言）：未选标签 4.90–7.87:1、选中标签 5.32–7.60:1、未选图标 4.54–7.44:1、选中图标 3.24–7.44:1；最紧的一处是浅色首屏的选中图标（3.24，图形下限 3）。
4. **未选文字深一档。** 原 `textFaint` 在蓝色图表透出时只有 4.25:1，低于 4.5:1 的文字下限，因此玻璃路径的未选标签与图标改用 `textMuted`（两种模式都 ≥4.9:1）。这是本次唯一一处语义色变更，`test/design_components_test.dart` 的期望与理由同步更新。
5. **阴影只在玻璃外。** 浮栏阴影用 `clipPath` 挖掉胶囊内部再绘制。薄玻璃会把身下的阴影透出来，第一版就是这样在栏内出现一条灰带的；挖孔后玻璃内部只剩内容本身的颜色。
6. **选中镜片。** 第二层更密的玻璃（浅色 55%/40% 白、深色 15%/10% 白）+ 更亮的顶边 + 自己的挖孔阴影；移动 180ms easeOutCubic，起步时横向 1.06 再回落（减动效时不产生过冲、首帧不播）。
7. **实色路径。** 高对比、未知或已请求减少透明度、模态覆盖时，浮栏与镜片用同一判定同时切实色；镜片改用新增的 `navigationSelection`（浅 #E6E9ED / 深 #343C46），修掉原来「白底浮白块」——实色下选中只剩颜色、没有位置标记的问题。边线同时改画在 `foregroundDecoration`，不再把实色容器撑大 1px，两条路径几何一致。
8. **顶栏保持磨砂。** 顶栏贴在内容上、静止时与 canvas 同底；浮栏悬在内容之上。两种材质职责不同，不合并成一种。

## 取舍与影响

- **不引入原生 Liquid Glass。** 折射、系统材质联动需要平台视图与地图兼容方案，验证面远大于浮栏本身，继续留在 ADR0012 的原生候选。本 ADR 交付的是 Flutter 合成的**近似**：光学参数静态、不随背景亮度自适应。
- **对比度有边界。** 玻璃压在正文、图表上时，最终对比由背景决定，对任意背景保证 4.5:1 与高透本身矛盾。本 ADR 的边界是「应用内表面（canvas / surface）与品牌色的透出」，越过边界的样本（照片、地图底图）按 R14 走实色，地图 route 已经实色。滚动过程中正文从栏下经过是转瞬的，两种材质都存在，这里不额外加不透明底衬。
- **成本。** 更大的模糊与一层挖孔阴影增加绘制开销，浮栏面积 358×64，仍是每 route 至多两个有界 blur 区域之一。性能按 #16 采样，不在本文下结论。
