# 鲜明度 v2：把「彩色」从细线与浅洗搬到亮面

- 日期 2026-11-19，状态 **accepted**，取代 [ADR 0016](0016-chromatic-language.md) 的 D2（三级强度）与 D3（彩色预算 5%/2%），其余 D1/D4–D7 继续有效。
- 用户当日指令（原文要点）：「引用对话的这次修改…比较成功…但我觉得还是比较收敛，不够鲜明活泼。…配色还可以再活泼、再鲜明、再大胆一点」。前置约束不变：无高饱和撞色、无渐变滥用、无霓虹感；浅深双模正文 ≥4.5:1；底栏不动。
- 配套：[色彩与图标秩序规格](../specs/chromatic-language.md) §12（CL49–CL58）、[实施记录](../implementation/chromatic-intensity.md)、样张 `docs/implementation/chromatic-intensity-renders/`。

## 背景

ADR 0016 把「1 个强调色」换成了「1 动作色 + 6 数据身份色相」，结构对了，但**像素没变**。逐像素实测（本机 iPhone 尺寸渲染，OKLCH 彩度 C 判据）说明问题不在色相数量：

| 页面（浅色首屏） | C>0.04 像素 | C>0.12 像素 | 平均 C |
| --- | --- | --- | --- |
| 概览 | 3.92% | 0.83% | 0.0105 |
| 行程 | 0.72% | 0.61% | 0.0060 |
| 充电 | 0.54% | 0.28% | 0.0031 |
| 统计 | 2.39% | 2.14% | 0.0135 |

也就是说 7 个色相并没有让页面「有颜色」，因为彩色仍然只出现在三处：**1.5–2.0px 的图表线、8% 的卡片洗色、20 号以上的彩色读数**。8% 的洗色合成到白底之后 C 只有 0.010–0.017——低于人眼「看得出这是彩色」的门限，实测行程/充电页几乎 0 彩色像素。

两条更硬的实测约束，说明「把现有色相调亮一点」这条路是走不通的：

1. **solid 已到色域边界**：六色相在锚定明度（L≈0.61–0.65，白底 3.55:1）上的彩度已达该明度色域边界的 95–98%（azure 0.185/0.195、aqua 0.100/0.105、mint 0.152/0.160、amber 0.123/0.129、coral 0.224/0.235、violet 0.238/0.251）。想更鲜艳只能降对比，而降对比就破 3:1 图形门槛。
2. **洗色 alpha 被正文门槛锁死**：洗色底上要放 strong 文字（5.90:1），实测 34% 时已掉到 4.50–4.58、40% 时 4.28–4.44。所以「加深卡片」的上限在 ~30%，而 30% 的深色洗色仍然只有 C≈0.03。

结论：**在「深色被白底对比锁死」的前提下，彩色只能靠换色阶的物理位置来变鲜明**——把面从「深色的淡洗」换成「亮面的浓洗」。

## 提议决定

1. **D1 新增「亮面」档（`MileafHueVivid`）**：六色相各一个值，统一 L=0.74、彩度取该明度下色域边界的 96%（azure `#6BAEFC` / aqua `#20C2C4` / mint `#20CB6C` / amber `#D5A21B` / coral `#FC7F86` / violet `#CC88FC`）。
   - 这一档**只做面的底色**，压在上面的字与字形取墨色（`#12161C`，实测 7.34–8.47:1）。
   - 六个值浅深两模式共用：亮面自带墨字后，唯一约束是「墨字还能读」，与底色是白还是近黑无关（对深色 canvas 另有 7.96–9.19:1）。
   - **亮面不能单独承界**：对白底只有 2.10–2.47:1，低于 3:1，所以它永远只以「洗色」或「带描边的点」出现（CL49.1、CL54）。
2. **D2 洗色改用亮面做原料，并且统一到 24%（深 22%）**：`veil` 40%（图表填充、弧环轨道，只压图形）/ `soft`=`tint` 24%（深 22%，小格与卡片背板）；入口卡另走 `deep` 55% + 墨字。同一张卡从 C≈0.01 提到 C≈0.026–0.055，也就是「从看不出颜色变成看得出颜色」。
   - 上限不是面积定的，是**前景**定的：卡内读数是 `strong`，24% 时最差格 4.56:1、26% 就 4.49:1。ADR 0016「面积越大 alpha 越低」的判断由此改写。
   - 代价是**面与前景的关系必须重写**：洗色底抬到 L≈0.94 之后，`solid` 压上去只剩 2.6–2.75:1（掉出图形门槛），所以**洗色面上的一切彩色前景一律取 `strong`**（实测 4.56–4.66）。solid 只允许直接压在 canvas / surface 上。
3. **D3 读数按字号分档取色**：display / metricLg / metricMd（40/32/24 号）属于 WCAG「大文本」，门槛 3:1，改取 `solid`（3.55:1）——这是全站彩色面积最大的一次性提亮；metricSm（20 号）仍取 `strong`。
4. **D4 图表：面与线分成两个色阶**：面积填充从「同色 16%」改成「亮面 40%→6% 渐变」，线/柱取 `strong`（浅色深一档、深色即 solid），主线 2.0→2.6、柱宽 12→16。未接色相的图表（hero 内嵌图）保留 16% 旧口径。
5. **D5 深洗底只给「入口卡」**：统计根页 2×2 章节卡改浅色 55% 亮面洗底 + 墨色文字（正文 11.4–12.0:1、次级墨字 6.9–7.1:1）。深色模式自动退回 tint——深底的 surface 已是近黑，55% 会把卡内读数压到 4.0:1 以下。记录分组卡（行程组 / 充电记录）取所属域 tint（24%），让列表页也有可读彩色面。
6. **D6 预算改为「高彩封顶 + 洗色放开」**（取代 CL06 的 5%/2% 与 CL07 的 ≤3）：高彩（C>0.12）≤5%（实测 0.28–2.69%）；洗色面（0.024<C≤0.075，只允许来自 `tint/soft/veil`）不设面积上限——它的彩度物理上限就是 0.075，本身就是「安静的大面积彩色」；100% 亮面面只允许 ≤6px 的点；单页首屏色相 ≤4。不变的部分：缺失/未知值永不着色。

## 未采纳的备选

| 备选 | 否决理由 |
| --- | --- |
| 把 solid 调得更亮/更饱和 | 实测已达明度色域边界 95–98%，再提只能降对比，破 3:1 图形门槛 |
| 白字压亮面（大字放宽到 3:1） | 亮面对白底只有 2.10–2.47:1，连大文本门槛都过不了；亮面只能配墨字 |
| 亮面填充的柱体 + strong 描边 | 图形卡本身是色相洗底，同色相亮面压在同色相浅底上只剩 1.5:1，远看像空心描边，比原来的实心柱更弱（已实现后回退） |
| 深色模式也用 55% 深洗 | 深色 surface 已是近黑，55% 后 azure 的读数（strong=solid）只剩 4.0:1 以下 |
| 整页背景上色（page-tint） | 「颜色 = 页面位置」与「颜色 = 数据身份」冲突（ADR 0016 已否决），且会让对比度守卫的全部底都变成变量 |
| 把底栏/弹层一起加色 | 底栏冻结（ADR 0013）；弹层背后已有 scrim，加色读不出层次 |
| 只加深现有 tint 的 alpha（不加亮面档） | 受正文门槛限制最多到 30%，30% 的深色洗色仍只有 C≈0.03，正是本轮要解决的「看不出颜色」 |

## 后果

**正面**
- 逐页高彩像素仍是 0.28–2.69%（5% 以内），洗色面从 0.5–3.9% 提到 0.7–55.3%（差别取决于该页有没有「一整块记录卡」），且**全部来自数据身份色**，不是装饰。
- 对比度不降反升：8% 深色洗底换成 26% 亮面洗底之后，卡内正文与次级文字仍 ≥4.5:1（实测 4.66–4.91，深色 5.37–8.20），墨字亮面卡 11.4–12.0:1。
- 「亮面」是一个可复用档位，而不是一次性调色：后续任何需要「鲜亮小面」的地方（选中点、徽标、地图浮控）都从这一档取，不必再造新色值。

**负面 / 风险**
- 彩色档位从 3 档变 5 档（亮面 / solid / strong / 洗色 / 深洗），**面与前景的配对规则变复杂**：洗色面上只能用 strong，solid 只能压中性底。规则写在 CL51，守卫按「色相 × 底」逐格断言。
- 亮面档在浅深两模式共用，意味着深色模式下**局部出现亮色面**（入口卡深洗退回 tint，但选中点、图表填充仍是亮面）。这是有意的（深色模式需要这些亮点），也意味着不能再用「浅色模式才有亮面」当默认假设。
- 入口卡（55%）与内容卡（26%）之间出现两档浓度，页面里会同时看到「很实的彩卡」和「很淡的彩卡」——这是层级，不是不一致，但需要逐页登记，避免某页只有一档。
- 彩色预算从 5%/2% 放宽到 12%/5% 之后，**「不花」的约束从面积预算转到了「色相数 + 面/前景关系」**：单页 ≤4 色相、面内前景只能同色相 strong、不得多色图标。这三条是新的主要防线。

**与既有决定的关系**：取代 ADR 0016 的 D2（三级强度）与 D3（5%/2% 预算）；ADR 0016 的 D1（色相寄存器）、D4（图标纪律）、D5（栅格）、D6（材质）、D7（动效）全部继续有效。CL12 的图标取色不变（仍 `strong`，因为它压在洗色面上）；CL15 的图表取色改为 `strong`（CL53）。

**外部 gate**：真机观感、真实数据、设备性能（#11/#16/#17）不因本增量关闭；本轮只做代码、自动化与样张，不推送。
