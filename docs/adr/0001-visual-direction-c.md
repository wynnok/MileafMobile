# 采用 C「数据拼贴」作为行笺的主视觉方向

- 日期：2026-10-30
- 状态：accepted
- 关系：取代 Spec #1 中原 A「湖畔」的页面布局与视觉验收；湖畔绿白/深绿与琥珀比较色保留。

## 决策

用户从 A「仪表舱」、B「行笺志」、C「数据拼贴」中选择 C。C 沿用湖畔绿白/深绿与琥珀比较色，只替换版面、字号层级与 bento 结构；统计页用“结论 + 主图 + 2×2 章节卡 → 独立专题页”替代当前五个等权 tab；行程详情以地图为第一视觉，充电详情以电池弧/SOC 与功率曲线为第一视觉；归期时区、完整采样口径与车辆资料收进“数据说明/更多”层，主路径只保留“非实时、估算、已知费用、覆盖不足”等影响判断的短提示。

数据口径、API、页面能力、只读边界与外部待验范围不变。C 使现有 A 的页面布局和视觉验收成为历史证据；Spec #1 已于 2026-10-30 追加 C 增量；相关 tickets 已按 C 更新验收，0 新票。

## 考虑过的选项

- **A 仪表舱**：深色车况主屏最聚焦、实现成本最低，但版面仍偏竖向叙事，用户已明确更喜欢 C。
- **B 行笺志**：纸面与衬线最有品牌气质，但信息密度低、实现更定制。
- **C 数据拼贴**：大小 tile 与满幅图能建立更强的视觉节奏，符合用户当前偏好；主要风险是 tile 过多导致新的平铺，因此约束为“每页一个主导 tile，200% 字号单列”。

## 影响

- 设计原型：`docs/prototypes/visual-refresh/`，并排图 `renders/compare-light.png`。
- 产品方案：`docs/product/visual-refresh-proposal.md`。
- Spec #1 已追加 C 增量；#8–#15、#17–#21 已追加 C 验收，#16 附性能注记；0 新票，不新增后端能力。
- 浅/深色、360×800、200%、空/缺失状态仍需新的 Flutter 实际渲染证据；旧 A 渲染不能作为 C 的视觉通过证据。
