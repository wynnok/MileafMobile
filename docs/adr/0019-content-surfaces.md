# 统一内容色面与玻璃材质

- 日期 2026-11-24，状态已采纳并实施。
- 色值及域色映射由 [ADR 0020](0020-jade-palette.md) 接续，色面强度与材质规则继续有效。
- 细化 [ADR 0018](0018-visual-hierarchy.md) 的非底栏视觉。用户反馈主卡着色、下方素白与统计专题独立色阶造成割裂，并要求保留页面布局。

## 决定

1. 六个数据域继续共用现有亮面原料。主读数用 48%／32%，普通内容和专题都用 24%／22%（浅色／深色）。行程记录与图表用蓝，充电记录与图表用青，续航与能耗专题用绿，停放与用车节奏用紫。跨域资料、系统设置与缺失数据用蓝灰中性色面。费用页主值保留琥珀。
2. 数据卡、分组卡、分段选中镜片、筛选和次按钮共享同一受光方向及边缘语言。色面固定，亮度变化集中在上沿，边缘随轮廓收起。滚动栏、锚定菜单、车选／外观等浮动选择器使用一层有界背景取样。贴边表单使用实色。原生地图浮控沿用实色合成回退。
3. 减少透明度、高对比或平台偏好未知时，内容卡保留域色并用实色边界，浮层切换为高密度实色。卡片读数在色面上取 `strong`。
4. 页面任务顺序、尺寸、导航和交互行为沿用现状。底部 Tab Bar 继续使用 ADR 0013 的渲染路径，浏览滚动内容时透底颜色随内容改变。

取值、页面映射与验收见 [VH15–VH18](../specs/visual-hierarchy.md#9-统一内容色面与玻璃材质) 和[实施记录](../implementation/visual-hierarchy-plan.md#统一内容色面实施)。

2026-11-24 更新：普通面与焦点面已改为分域固定色值。现行取色见 [ADR 0021](0021-sky-mint-palette.md)。
