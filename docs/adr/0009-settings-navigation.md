# 设置首页按使用偏好与当前站点分组

2026-11-09，用户确认本方案并授权按 implement 完成。修订 ADR 0008 的地图入口层级，视觉沿用 ADR 0003 与 ADR 0006。

设置首页使用「使用偏好」「当前站点」两组。地图与外观属于设备偏好，站点连接、币种和服务信息属于当前站点。地图从首页直接进入配置页，并显示配置状态。原入口「服务版本与兼容性」到「设置与服务」存在命名歧义，且将地图藏入技术信息层。首页由独立 SettingsPage 承担，工作区及暂无车辆页使用同一入口。[工作区](../../lib/src/workspace_page.dart)、[设置首页](../../lib/src/settings_page.dart)

连接管理页改名「站点连接」。先呈现当前地址与连接操作，用户选择「更换连接」或「重新登录当前站点」后展开编辑。表单错误靠近提交按钮，退出操作独立置底。这样首页以选择配置为主，候选地址与口令的编辑集中在连接页。[连接管理](../../lib/src/connection_management.dart)

服务信息页只承担版本、兼容性及数据说明。采用现有语义色、字号阶梯、细线列表和响应式留白，不引入新的配色体系。表单保留候选连接验证成功后才替换的行为，设置导航在会话更换或退出时返回主路由，避免保留旧站点偏好。[服务信息](../../lib/src/overview_page.dart)、[规格](../specs/settings-navigation.md)
