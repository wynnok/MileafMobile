## 背景

行笺已经过三代设计收敛：ADR0011 统一排版与任务层级，ADR0012 引入内容表面、磨砂导航与连续反馈，ADR0013 把底栏做成液态玻璃并在 2026-11-18 再透一层，ADR0014 以单一重心、统一语法和清晰文案完成 Apple 质感精修（R21–R32，实施中）。参考 App Days Matter 同样是 Apple 校准过的 Compose 体系（Material 3 + Haze，令牌集中于 `Theme.kt`，注释明言「Screens never use literal values」）。

对齐审计的结论：**两者在理念层高度同构**——单强调色纪律、分组内嵌列表加发丝线、玻璃只用于 Chrome、动效只解释状态、状态排成内容而非 toast，这些行笺已由 R21–R32 与 M01–M12 覆盖。因此本增量**不做推翻式重构**，净增益集中在六个可核查的收尾点（规格 MG01–MG09），并把参考 App 值得学习的两条纪律（彩色面积有预算、对比度校验自动化）落成守卫测试。

## 提议决定

1. **迁移映射（六条理念 → 判定）**：一屏一个数字主角【需改造：重心规则沿 R21，迁移「数值变更不跳变」全站纪律】；单强调色纪律【可迁移：新增彩色面积预算与状态取色映射表】；分组内嵌列表加发丝线【需改造：结构沿 R24，收尾「行程记录行句法统一」与深浅分层策略】；材质三分【可迁移：材质登记表与内容层玻璃守卫；Hero 独立墨色材质不迁移】；动效解释状态【需改造：白名单沿 R07/M01–M12，扩展 M08 到全部焦点值变更；按压弹簧不迁移】；状态诚实【可迁移：状态三要素「现状句 + 时间或原因 + 下一步动作」落到 StateView 与状态条】。全文见规格 §3。
2. **不迁移清单（元素层，禁止照搬）**：参考 App 的页面四段式结构、悬浮三槽底栏、图标瓦片造型与 83 图标库、全部色值（含 tint 七色带、墨色 Hero 渐变）、间距与圆角具体数值、弹簧参数与时长数值、文案措辞（口语化情感句式）。底栏液态玻璃（ADR0013 L01–L12）为不可改动范围，本增量不触碰。
3. **新增工程纪律**：彩色面积逐页登记（非图表彩色面积 ≤20%）；状态取色映射表（缺失与未知数据永不使用彩色信号）；语义前景×背景对比度自动化守卫（裁决 textFaint 两份实施记录的矛盾，以 WCAG 复测口径为准，取值不变）；图标家族参数登记与统一出口；材质三分登记表加内容层玻璃 import 守卫。
4. **待确认决策点**（转为 accepted 的前提，推荐意见见规格 §8）：
   - D1：卡头→焦点值间距 `s4` → `s12`（解决 period-header 遗留裁定，按 R21.6/R24 字面采纳；360×800 首屏预算由页面包实测回收）。
   - D2：底栏镜片受光带维持默认关（不迁移参考 App 的高光渐变性格，维持 AP02 现状）。
   - D3：动效时长集合维持现行 {120…280} 七档与两族曲线（用户约束中的「200–350ms」为示例值；现行集合同类一致、状态档全部 ≤200ms、M 系列已经用户确认）。
   - D4：Hero 不引入参考 App 式独立墨色材质（沿外观 v2 与 PD06 的「hero 落普通卡面」裁定）。
