# Triage Labels

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交由 agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能使用角色名时，采用上述映射。
需求准备材料不能直接标为 ready-for-agent。
