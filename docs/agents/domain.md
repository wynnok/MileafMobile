# Domain Docs

## 布局

本仓库采用 single-context：根目录 GLOSSARY.md 和 docs/adr/。
不采用 GLOSSARY-MAP.md 或按子项目拆分领域文档。

## 阅读规则

- 探索前读取 GLOSSARY.md 和与任务相关的 ADR。
- 文件尚不存在时直接继续，不为补齐目录创建空文档。
- 使用词汇表中的领域术语；发现术语缺口时记录，避免自行引入同义词。
- 与既有 ADR 冲突时明确指出，不静默覆盖。
- MileafServer/ 和 teslamate/ 为外部仓库的只读参考入口，
  不在移动端任务中修改其内容。
- 后端词汇表、范围文档和 API 文档是参考材料；
  当前 API 能力需结合实际路由、模型及测试核实。
- 产品建议、用户确认的决定、代码事实分别标注，
  不将未确认建议写成已接受的 ADR。
