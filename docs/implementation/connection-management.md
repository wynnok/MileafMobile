# Ticket #7：安全替换连接与本地退出

## 已实现的 App 路径

临时车辆页的设置入口调用 `openConnectionManagement(context, session)`；后续业务壳直接复用此入口。独立页面提供当前地址、同站点重新登录、候选连接与退出此设备。地址、口令和 HTTP 确认是候选页局部状态；提交立即清空口令。

候选使用统一 MileafApi，依次读取 health、POST auth/login、GET vehicles；健康及登录不携带当前 token，车辆仅携带候选 token。全部成功并且安全记录持久化成功后才发布新 SiteSession（即使是同站点也创建新代次）与车辆列表。任何阶段失败保留当前站点与车辆。HTTP 授权以规范化后的完整连接（协议、主机、端口和代理前缀）为键；修改输入后不继承当前勾选。服务器限流期间禁止再次提交候选认证，不自动重试 POST。

会话替换与退出都沿用唯一安全 JSON 记录及串行写队列，不增加第二份 token 存储。业务模块必须监听 SessionController，使用 `isCurrent(capturedSession)` 校验每个响应并在 current 对象改变时清空自己的选择/内存缓存；相同车辆 ID 不表示相同授权。旧成功和旧 401 不具备更新新代次的权限。

退出立即清空 current、车辆与旧在途结果权限，并把安全记录替换为只含地址。仅结束此设备访问，不发送不存在的 logout/revoke 请求。安全写失败明确提示未清理成功，保留重试入口，不声称重启已安全。退出后的登录页可编辑保留地址，复用启动连接页的健康检查及可信 HTTP 授权，不复制第二套策略。

## 已验证

App + 可控 HTTP 行为测试覆盖候选登录/车辆失败、存储写失败保留旧连接，候选成功后重启恢复新站点；同站点及跨站点两代次的旧成功/401 晚到；退出后的成功/401 晚到、候选登录晚到、重启不恢复授权；退出清理失败可重试；HTTP 授权按代理前缀隔离；退出后编辑地址重新健康检查。测试存储仅代表系统存储边界，不证明 Keychain/Keystore 加密。

## 外部待验

Android/iOS 真实安全存储写入→退出→杀进程→重启、真实站点替换、发布构建及平台网络恢复仍待外部设备/站点条件，不作为自动化通过结论。Ticket #7 保持开放；代码依赖可依用户 2026-10-23 授权推进，原生阻塞边保持不变。
