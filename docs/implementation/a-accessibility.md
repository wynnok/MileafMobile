# A「夜航」可达性与对比度审计（VA13）

日期：2026-11-01 · 分支：`codex/mileaf-v1` · 范围：A 视觉系统 VA01–VA14 的自动化可达性检查。

## 结论

- 语义色对比度表全部通过（深色/浅色，见下）。
- 共享组件触控目标 ≥44dp：图标按钮、chip、按钮、可点 metric、图表选点。
- 图表均有语义摘要与当前读数；null 读数朗读为缺失，真实 0 保留。
- reduce motion 下页面位移/图表绘制直接完成，只保留 opacity。
- 状态/错误使用文字 + liveRegion，不只靠颜色；比较方向用箭头与文字，不用红绿。
- 200% 下共享组件与四主 Tab/详情/专题的关键测试无横向溢出。
- 真机读屏（TalkBack/VoiceOver）、真实设备字体回退与真实对比度仍未验证，见「外部 gate」。

## 屏幕阅读器顺序（按页面）

1. 概览：品牌/车辆/设置 → 状态（liveRegion）→ 续航 → 电量弧 → 今日三项 → 本月 → 主图读数 → 辅助读数 → 最近 → 继续 → 数据说明。
2. 行程：页头/区间 → 期间主数 → 节奏读数 → 最近的路（每条起终点、时间、净电耗、距离）→ 加载更多 → 数据说明。
3. 充电：页头/区间 → 费用 hero（含覆盖）→ 三读数 → 每日补能读数 → 构成 → 地点账目 → 最近一次 → 数据说明。
4. 统计：结论 → 主图读数 → 洞察 → 四章节 → 全部指标/数据说明。
5. 详情：地图（失败为路线示意）→ 覆盖说明 → 三结果 → 曲线读数 → 电量区间 → 技术信息 → 脚注。
6. 专题：结论 → 主数 → 主图读数 → 证据 → 数据说明。

## 非颜色编码

- 比较方向：`↑`/`↓` + 文字（`MetricDelta`、`_mileageDeltaText`）。
- 参照：虚线 + `参照` 图例/读数，不只靠 sand 色。
- 状态：文字「非实时」「进行中」「已结束」+ 颜色/圆点。
- 构成：AC/DC/未知均有文字标签与数值，不只靠分段色。
- 缺失：`—` 与说明，不用 0 代替。

## 外部 gate（仍未关闭）

- TalkBack（Android）与 VoiceOver（iOS）真机顺序、焦点陷阱、图表增减手势。
- 系统字体（含中文）200% 在真机的实际换行与截断。
- 真实设备亮度/屏幕下的对比度与色弱模拟。
- 高德地图底图/标注的可达性与版权标识可读性。
- 性能与双端隔离构建的最终验收。
