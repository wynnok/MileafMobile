# Ticket #6：显式初始化站点

只从登录页的“首次设置站点口令”进入独立 SetupPage，不因 health 或登录401自动探测/调用 setup。
两次输入需一致，最少10个Unicode码点，对齐当前后端 Python 的长度规则。提交即清空控件内容，
既不持久保存明文口令，也不写入日志。输入、错误和按钮可滚动阅读，初始化进行中禁重复提交与返回。

SessionController.initialize 复用唯一 MileafApi 请求边界，匿名 POST auth/setup。
成功确认 status=ok 后才复用既有 login/安全会话/车辆读取；登录失败仍回普通登录，不能再次自动初始化。
返回值表示已完成设置或确认站点已初始化，应回到正常登录/业务流程，不是“登录必定成功”。
409且code=already_initialized只提示使用已有口令登录，不自动尝试新口令。
传输超时/断连说明结果未确定，用户可先尝试登录或主动重试，不自动重发可能已生效的POST。

所有请求继承准确站点HTTP授权、HTTPS证书验证、禁止跳转和15秒截止时间；设置口令并不绕过接入策略。
在途结果仍核对会话代次和站点，所有凭据持久化继续由已有login的单一记录及串行队列负责。
