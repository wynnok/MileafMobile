## 关键判断（与票面措辞的差别，均已按规格原则修正）

1. **图与读数跟指标走，不跟页面走**。票面写「每日充电图 energy」，但该图的指标胶囊可切电量/费用/均价/次数；若固定 energy，切到「费用」时同一指标在记录行是 cost、在图上却是 energy，违反 CL01「同一指标同一色相」。实现按所选指标的域取色（充电 页判据 `metric >= 1 && metric <= 2` → cost），页面色相数仍 ≤2。同类修正见概览主图（`_metricHue`）、统计专题主图。
2. **「与近 30 天相比」本期不要用 journey**。电耗的色相是 efficiency（CL01），本期与参照要同属一个域；参照系列用中性 `reference`。主控最初在提示词里写成 journey，已按 CL01 纠正。
3. **缺失值不染彩色**（CL08）。所有页面统一用 `value == null ? null : domain.hue`：缺失时 `MileafNumber` 自己画「—」，不进彩色分支。

## CL13.2：身份块标题不带前置图标（本轮的设计回退）

第一版把 16 身份图标放在 `SectionHeader` 标题前。两个既有不变量立刻被打破——`ui_ux_u09d_test` / `ui_ux_u09e_test` 的「宽屏专题主体限宽并与标题共享左线」断言 `card.left == 标题文字.left`（R24：卡片外缘与身份块标题共享左线）。前置图标把标题文字推走 24px。

裁定：**保住对齐，撤掉标题行的图标**。理由不是「测试难改」，而是参考 App 本身也这么做——它的身份色在**行内瓦片与洗色**里，区块标题是纯文字（`reference-language.md` §6.4：界面图标一律中性、身份图标只出现在行）。行笺的可移植落点是：

| 载体 | 是否带身份色 | 依据 |
| --- | --- | --- |
| 读数（MetricBlock / MileafNumber） | ✅ strong | CL12，彩色落在数字上 |
| 图表系列 / 弧环 / 柱 | ✅ solid | CL12 |
| 卡片背板（焦点卡、章节卡、结论卡） | ✅ tint 8% | CL02/CL06 |
| 行首图标（MileafGroupRow.leading、MileafFact.icon、用车专题行） | ✅ strong | 行内，不参与「标题—内容同左线」 |
| 区块标题（SectionHeader / MileafPeriodHeader） | ❌ | CL13.2：R24 左线优先 |
| 按钮图标 | ⭕ 按钮前景色（动作色） | CL12.1：动作图标不得染语义色相 |
