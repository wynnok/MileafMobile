# 设置页秩序重排（设置首页 + 地图设置页）

> 2026-11-18。用户指出「设置」页面（截图为设置 → 地图页）元素排版与对齐失序，要求按「克制、精致、一体性强、有秩序感，注重排版层级与微动效」重做。本切片只动呈现层：不新增颜色/字号/圆角/动效 token，不改 `MapKeyController`、授权语义与冻结文案；玻璃与阴影仍只在导航与浮层（ADR0013、ADR0014 §1.2），内容卡保持实色。

## 2. 改动

### 2.1 地图设置页 `lib/src/map/map_privacy_page.dart`

- **本机配置卡**固定为「结论 → 配置 → 破坏操作」三段：
  - 状态块：图钉 20（`accent`，全页唯一强调色对象，尺寸与各设置行行首图标一致）+ 状态句（`body` 600，按状态着色 `text/warning/error`）+ 范围句（`footnote`，`textSecondary`；待重启态为 `warning`），块内边距 16/12；状态句变化按 §4 M08 用 120ms 透明度交接（`AnimatedSwitcher`，减动效归零）。读屏只有一个 live region：`Semantics(liveRegion, label, excludeSemantics)` 包在切换器外层，label 首帧即新值，交接期内层双 `Text` 不进语义树，不重复播报。
  - 状态块后一条 1px 细线，从状态文字起始处（16+20+12）画到卡片右缘（R24）；缩进与图标尺寸共用同一 token 组合，改图标不会静默错位。
  - Key 摘要行 / 表单 / 进度线全部有 16 内边距；表单底 16、顶 12。
  - 「清除已保存的 Key」是组内最后一行的独立 error 细线行（`topLine`），**与读取状态无关**（读取失败、重试失败时仍可清除），确认弹窗与文案不变（CP12 冻结）。
- **结果句与错误句移出卡片**：保存/清除的结果句与已保存折叠态的保存失败句，落在卡片下方的画布层脚注（`footnote` 13，错误句 `error` 色），与分组标题同一条起始线；`Semantics(liveRegion)` 保留。保存结果句按 ADR0010 §2 边界 4「允许精简文案并同步教程与测试」精简为「打开详情地图后可查看加载结果。」——删去的「Key 已保存在本机。」与状态行「已保存」+范围句重复；该句不在 ADR0010 D7 冻结清单内，`docs/tutorial/` 与测试均无引用（已 grep 确认）。冻结串（`保存 Key`、`清除已保存的 Key`、`如何申请 Key`、状态字串等）逐字未动。
- **申请帮助 / 地图隐私**：折叠行与内容补齐内边距；折叠内容左缘 16、右缘不收，`MileafCopyRow` 的分隔线仍画到卡片右缘；步骤、脚注等文本右缘按 16 收拢；绑定读取失败仍用 `InlineBanner`（M11）。
- 分组标题（本机配置/申请帮助/地图隐私）与脚注对齐卡片内边距（页面 + 16，R24 两条起始线）。

### 2.2 设置首页 `lib/src/settings_page.dart`

- 「使用偏好」「当前站点」两个分组标题与「未配置地图时显示路线示意。」脚注改对齐卡片内边距（脚注 `cardInset` 12 → `cardPad` 16）。行结构未动（已符合 P12）。

### 2.3 共享组件

- `MileafGroupHeader` 新增 `inset`（默认 0，additive）：R24「两条起始线」的卡内用法收进设计层（R32），设置两页传 `MileafSpace.cardPad`；其余页面按 AP13 迁移时逐页传入，默认行为零变化。
- `MileafDisclosure` 新增 `inset`（默认 0，additive）：卡内用法给头部两侧与内容左缘补内边距；默认值保持页面上「共用起始线」的既有用法，其余调用方零变化。
- `MileafCopyRow` 右缘补 `cardPad` 文字内边距（非参数化调整；全库仅地图设置页使用，分隔线仍从自身左缘画到容器右缘）。
