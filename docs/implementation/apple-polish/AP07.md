## 3 总控定位（代码事实）

### 3.1 概览「电耗对比」

- 页面当前有三套内容左缘：区块标题在页边距（16）；开放行 `MileafDataRow` 在页边距（行首图标 16、文字再 +32）；卡片内容在页边距 + 卡内边（16+16=32）。`MileafDataNotes` 的组标题在卡外 16、行文字在卡内 32。用户看到的「有背景框和没有背景框内的文字也不对齐」即此三套左缘。
- `_recentSection` 与 `_continueSection` 的行直接铺在页背景上，用 `topLine`/`bottomLine` 画整行发丝线；`_comparisonSection` 却是 `SectionHeader` + `MileafModuleCard`。有框 / 无框混用，使 `电耗对比` 像临时插入的一段。
- `电耗对比` 是 AP07 新增的独立段（规格 P01 线框没有这一段）：一张卡里只有一句正文 + 一个 ghost 按钮，层级与留白不成体系；`查看对比明细` 的按钮描边又制造了第三层容器感。
- 标题下、末行下的整行发丝线穿过页面内容区，与卡片边缘不一致，放大「没有秩序感」。

### 3.2 行程列表

- `_recentSection` 把 `MileafDataRow` 直接放进 `MileafGroupCard`；`MileafDataRow` 只有纵向 `s12` 内边，**没有横向内边**。用户截图中「清鸥府 → 好花红镇」距卡片左缘约 4 px，`92.0 km` 距右缘约 4 px，文字等于贴着卡片边。
- `_routeRow` 对每一行都传 `bottomLine: true`（`drives_page.dart:808`），包括每天最后一行；`MileafGroupCard(clip: false)` 不裁剪，最后一行底部分隔线正好压在卡片底缘并突破圆角，形成用户说的「背景框下方还有一个横线条」。
- 分组标题在卡外页边距、卡片文字在卡内近边缘，左缘不一致；行与行之间没有统一的分隔线体系（只有每行底部线，末行也画）。

### 3.3 充电页顶部与「查看全部充电记录」

- `build` 先放 `_pageHeader()`（`charging_page.dart:1627`，右对齐「全部记录」+ 刷新圆钮），再以 `MileafSpace.s4` 放 `_periodRow()`（近 30 天 / 近 7 天 / 自定义日期）。第一行左侧整片空白，第二行只有胶囊，视觉上是两行、一片空。
- `_recentSection`（`charging_page.dart:1980`）在最近记录之后放一个整行左对齐的 `TextButton`「查看全部充电记录」，没有与记录行、卡片内容或页边距对齐，独立悬浮。
- 规格 P03 与文案 CP05/CP06 已定：期间行与刷新同一行；「全部记录」入口改为「最近的充电」区块标题尾部「查看全部」；进入后的二级导航标题是「全部充电记录」；不再保留整行按钮。

### 3.4 统计专题网格

- `_questionTiles` 直接跟在结论卡后，**没有上间距**；同行卡片用 `Row(crossAxisAlignment: start)`，两卡按各自内容取高，所以「节奏 / 能耗」「补能 / 长期」不等高（AP07 交接 D-AP07-06 已登记，用户本次把它判为不通过）。
- 图表 X 轴标签落在结论卡底缘，专题卡紧贴其下，读成「叠在一起」。需要明确的分区间距（≥s12，建议 s20）与图表底部标签呼吸。
- 大字时专题卡已改单列；100% 下的等高不能靠固定高度解决，需用行级拉伸或等价方案，且不能破坏 `MileafNumber` 的 `LayoutBuilder`。

## 4 验收标准（复评逐条对照）

1. **概览**：区块标题、卡片内容、开放行首图标落在统一内容网格；卡内文字距卡片左右缘 ≥12（建议 16）；不再出现只有 4 px 内边的行；「电耗对比」与「关于这些数据」使用同一容器语法，标题与正文/动作的层级清楚，去除多余卡中卡或整行发丝线；200% 与 320 宽不溢出；R21.1 每视口仍只有一个 display / 一个 metricLg。
2. **行程**：所有记录行走组卡并具备统一横向内边；只在行间画分隔线，每天最后一行**不画**底部线；卡片圆角完整；分组标题与卡片内容按同一页面网格对齐（二选一：标题与卡内文字同左缘，或标题在卡外 16、卡内文字 32，并在交接中记录所选网格）；320/200% 不溢出；首屏预算（第一条完整、第二条起始 ≥24）不退让。
3. **充电**：顶部只保留一行控件（期间胶囊 + 刷新圆钮），不能出现左侧空白的第二行；「全部记录」入口改为「最近的充电」区块标题尾部「查看全部」（P03 / CP06），删除整行「查看全部充电记录」按钮；二级导航标题仍为「全部充电记录」；320/200% 不溢出；不改变既有路由与请求。
4. **统计**：结论卡与专题网格之间加明确分区距（≥s12，建议 s20）；同一行两张专题卡等高（高度差 ≤1 px）；图表 X 轴标签与专题卡不重叠；200% 单列；首屏预算（用车专题第一行两张卡片完整可见）不退让。
5. **通用**：`analyze` 无诊断；本票测试全绿；全量 `tool/flutterw test --no-pub` 0 失败；`dart format` 0 changed；`git diff --check` 无输出；冻结文案逐字未改；不新增公开符号；不修改冻结组件（tokens / layout / controls / content / charts）；不改 AGENTS.md；不推送。
