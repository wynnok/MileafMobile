## 2 最终用色、材质与对比度

色值按 sRGB 合成，以 `(Lmax + .05) / (Lmin + .05)` 计算六域的最差对比度。焦点辅助字与底色随主题同步切换。统计按压保留描边和短时叠色，电量弧在染色底上使用更深的前景档。

| 对象 | 浅色最低值 | 深色最低值 |
| --- | ---: | ---: |
| 焦点主文，六域 | 12.15:1 | 8.54:1 |
| 焦点辅助字，六域 | 6.69:1 | 5.48:1 |
| 彩色入口辅助字，六域 | 7.89:1 | 6.98:1 |
| 焦点操作，含按压叠色 | 4.74:1 | 4.95:1 |
| 非底栏玻璃正文，浅覆纯黑／深覆纯白 | 14.94:1 | 12.53:1 |
| 同上，辅助字 | 4.70:1 | 6.54:1 |
| 同上，动作蓝 | 4.73:1 | 5.64:1 |

玻璃的模型输入为滤镜输出的 sRGB 显示色。浅覆纯黑为 `#E6E6E6`，深覆纯白为 `#2A2D33`。表中深色辅助字为 0018 标准配对 `#A7B4C2` 算例，实际各控件仍按本身语义取色。`MileafGlassSurface.control` 共用滤镜与边缘计算，贴合屏幕的顶栏只保留自身下沿，镜片与浮层保留完整受光边。原生底图先走实色回退。
