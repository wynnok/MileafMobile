## Root 补查（不改变原两轴发现计数）

- **充电分页进度与滚动来源**：原程序 `ensureVisible` 滚动会多发一页并可能在布局期 `setState`。现在仅用户向下拖动且接近底部自动翻页；重复 next_cursor 给出“分页游标未前进”并停止自动请求，保留记录及显式加载更多/局部重试。360×800、200% 字体 App/HTTP 回归证明程序滚动不翻页、重复游标停止、继续拖动不增加 GET、手动重试可到末页；原失败保留/去重/刷新/304 回归继续通过。
- **统计当前日窗口 TTL**：原当前区间每次前台 resolve(now)，TTL 内也会产生新缓存键而读网。现在缓存绑定实际查询与请求时的选择，TTL 有效且同日/同时区/同选择时保留当前 kind；过期推进今天截止，历史边界固定，不活动 kind 不加载。默认/含今天自定义/历史自定义 App/HTTP 回归先红后绿；另补换区间失败后恢复，防止旧有效缓存阻止新选择恢复。
- **币种偏好恢复竞态**：在既有 App 与系统偏好注入边界延迟初次 read，先选择 USD 再返回旧 CNY，原行为费用被覆盖。最小 revision 保护使迟到恢复不覆盖用户选择；同一 App 回归修复后保持 USD。
