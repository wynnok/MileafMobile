## 充电主页与记录

- 期间默认近30本地日，支持近7日及原有自定义日期；标题标明结束日或旧服务开始日、时区和窗口。统计/地点最多730天，长区间仍能浏览记录。
- 0.2主页显示已知费用和覆盖、入电及有效覆盖、服务端配对有效均价、记录时长及有效覆盖；缺失与真实0分开。一个日图可切入电、费用、有效均价、次数，保留时间、单位、真实桶、选点及前后日辅助操作；结束日下钻使用同一查询条件。
- AC/DC/未知入电采用同尺度图，DC占比以已知分类为分母；分类时长与覆盖单独标注，不补算损耗或未知能量。地点账目使用服务端稳定键、聚合及游标；同名不由客户端合并，点地点以相同键查询列表和统计。
- 全部记录有直接入口，搜索与分类/费用/地点筛选、排序作用于完整服务端匹配集；匹配数不取已载页。筛选变化重置游标和旧结果，筛选上下文在账本中可见。有效单价排序由服务端执行，单次单价在详情查看，不逐条预取详情或由客户端补算。
- 结束日列表只含已完成会话；另外按开始时间读取最近20条记录，单独展示其中的未结束会话，不纳入完成统计。该有界读取不是完整未结束历史查询；旧服务原列表继续按开始日展示。
- 期间统计、地点、记录、未结束会话和能力查询独立失败/恢复；同查询的条件304复用已授权快照，查询变化清除不匹配的结果，迟到响应受会话、车辆与请求序号约束。各区块校验时间是客户端检查时间，不冒充车辆采样或跨端点原子快照。

## 单次回顾与统计

- 新契约详情前置地点、补能、费用和起止SOC。功率/SOC及支持的电压、实际/引导电流、室外温度、额定/理想续航和累计入电可按真实时间读取；另可按0–100% SOC查看相同采样，重复SOC仍按时间顺序保留，缺失断线，点按/拖动及前后点可读。
- 原始功率峰值、时间加权均值、覆盖秒数和20–80质量状态直接使用服务端结果。`crossed` 显示实际记录端点，不伪称精确20%或80%；进行中和质量不足不展示确定用时。布尔加热事件使用离散标记和可展开明细，截断明确提示；不推断加热耗能。
- 两侧能量同单位比较而不相加；单次费用和两种有效均价分母分别命名。充电器品牌/类型/线缆与来源采样时间只使用服务端事实，不由DC或地点推断。额定/理想续航、室外温度及不支持字段标明口径。
- 充电统计页在0.2响应中使用有效配对均价和覆盖，并展示未知分类及三类时长；旧 `cost_per_kwh` 在旧响应保留原口径。区间总值和比率直接取服务端，不平均桶比率。
