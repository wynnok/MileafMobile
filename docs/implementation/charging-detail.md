# Ticket #13：充电详情与采样曲线

## 交付

概览最近充电与充电历史记录共用独立详情导航，详情捕获当前站点会话与车辆，响应核对记录 ID / vehicle_id；当前会话或选车变化时退出旧路由。明细和序列各自加载、缓存、刷新、错误和重试，一个区域失败不覆盖另一区域；刷新失败保留明确标注的已有快照。404 解释记录不可用并提供返回，401 依既有会话机制退出；旧响应不能恢复内容。

详情区分充入电池与电网侧能量，按已有结果展示费用、平均外温、时长、起止时间、电量和 AC/DC/未知。沿用 WorkspacePage 同一 CurrencySettings：只添加站点币种代码，不改数字、不换汇。is_active 标记进行中，null 不伪造最终值，0 保留真实零；不生成费用组成、温度序列、积分电量或峰值结果。

序列请求固定 fields=power,soc / points=200。冻结 OpenAPI 生成 ChargingSessionDetail、ChargingSessionSeries 与引用闭包；ChargePoint 仅 t 必填，省略和 null 的指标均保留未知。独立输出可用项目包装器运行生成器并指定这两个根复现，无新客户端或图表依赖。

## 图表行为

功率 / 电量切换保留真实时间位置。横坐标按 t 的实际时间差定位，点选使用时间位置最近的实际采样点；有效点按同指标相邻连接，null/省略的点断线，0 正常绘制。0 点明确空态，1 个或不足两点只显示实际点及读数，不补点或补零。长时间差不自行推断缺采，连线以低强调方式并解释仅为采样示意、非连续观测；采样峰值不等同原始峰值。

每个采样点均有可聚焦文字按钮，提供时间、单位和缺失读数；图表点选和文字按钮共享同一选中读数与 live-region，支持屏幕阅读器路径。360 宽、200% 字体采用换行布局与纵向滚动。

## 已验证与待验

通过完整 App 与可控 HTTP 验证两种入口、固定实际 HTTP 详情/序列样本、进行中和 null/0、币种标签、明细/曲线独立失败重试、200→304、错车拒绝、404 返回、当前401路由清理及迟到序列隔离、不等间隔点选、空/单点/省略字段，以及 360 宽 200% 字深色。既有充电历史导航测试更新为真实详情目标，错误映射同步保留 ApiFailure.message，便于共享请求限流策略给出准确说明。

固定样本来自本项目已有隔离合成数据库真实 HTTP 输出，不是用户数据。真机屏幕阅读器、系统返回、真实站点的完整详情与采样对账仍待外部验收。Ticket 保持开放，不修改原生验收阻塞关系；不将模拟 HTTP 测试或构建等同真实站点/真机通过。
