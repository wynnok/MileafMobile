## 实现结果

- 列表费用旁与详情费用位置共用 `ChargingCostAction` 和同一底部表单；ghost入口按内容宽度收缩，大字下单独一行。读操作继续可用；版本或记录不符合条件时不显示入口。
- 统一预检详情、车辆与会话身份；唯一输入为本次单价，按十进制定点算法预估总费用，采用两类能量的较大可用值与half-up两位舍入；0单价与正单价舍入为0分别说明。
- PATCH沿用鉴权与网络策略，单价以字符串发送。已知费用含0不覆盖；输入不保存、不设置默认单价、不默认人民币。
- 403保留输入并说明站点未开启；400/422就近校验；404停止操作；409先查询。超时/5xx/响应异常进入结果待确认，先查询后由用户显式重提，不自动重发。
- 提交期间禁用重复提交、编辑及普通关闭；401/身份变化移除旧表单，异步结果不再更新旧上下文。
- 写入成功或查询到已有费用后，按当前授权范围失效相关快照及在途读取，刷新已挂载的详情、充电、概览和统计页面。费用刷新不是车辆revision，不重置Tab或筛选；充电列表重新读取已加载页数，不因刷新退回首个分页范围。
- 写入已确认但汇总读取失败，仍报告补录成功并提示汇总待刷新；不把预估金额加到图表或恢复提交。费用详情刷新保留地图与曲线，避免无关下载。

```sh
./tool/flutterw dart tool/generate_auth_contract.dart \
  --spec=docs/contracts/openapi-charging-cost-0.4.0.json \
  lib/src/charging_cost_contract.g.dart ChargingCostResult
```

请求只编码已校验的字符串单价；不为支持number/string联合输入而改造整个生成器。结果使用生成DTO，再核验记录ID、请求单价、有限非负十进制与计费电量范围；不直接把任意200当作成功。未启动后端、未访问数据库、未变更生产权限。
