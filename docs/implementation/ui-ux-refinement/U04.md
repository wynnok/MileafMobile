## 改动及实现选择

- 产品只修改 `lib/src/overview_page.dart`。冻结文件、DTO、依赖与原生地图均无改动。
- 车况使用页面内 `_statusSurface` 组合既有 MileafContent、Material 与共享颜色/圆角/间距。共享 MileafHero 仍按旧浅深策略推导满幅，U04 仅持有概览文件，因此在页面组合卡片以落实 R04。没有新增主题、颜色或排版角色。顶栏移到车况前，浅深模式均保持外壳→车况顺序。
- 本地首屏测量使用正式字体、360×800、padding/viewPadding top24/bottom24、DPR1。车况高 207。绘图区使用共享 Painter 的实际 plot 矩形测量，排除轴留白，实际 plot 全局坐标为 `(43.6,589)–(340,749)`，viewport 底为 712，可见 123。body 顶以外壳底为 0，底为底栏顶。
- 期间控件使用共享轨道，四指标保持里程/电耗/补能/费用。`_Metric.energy` 分支保留，驾驶消耗仍在说明。图形即时显示，日里程采用共享柱图和零基线，新增 Y 轴和显式单位，里程参照标注上月同期/前一区间，周期差值旁列真实基期范围。读值追加实际参照范围、原值和绝对差，净电耗差值复用 canCompare，口径/覆盖未可比只展示原值与限定。
- 周期辅助区按行保留净电耗、已知费用、补能总量、驾驶趟数、币种和费用覆盖，估算与缺失费用限定就近可见。最近行程/充电各一个，记录与原下钻不变。
- 缺失续航显示 24 号「— 暂无续航」，SOC 未知显示「电量未知」，避免空弧与大破折号占据主要空间。今日已知值保留。
- `data==null` 时仍呈现驾驶/补能数据说明，车况故障不再隐藏独立成功的统计明细。首次驾驶失败时保留四指标控件，可实际切入独立成功的补能/费用图。
