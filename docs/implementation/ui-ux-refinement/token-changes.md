## 共享组件候选

- TimeSeriesChart 的 height 现在明确为实际绘图区高度，文字轴、标记留白自然追加。Y轴通过同一范围计算和TextPainter实测留白，放大时减少到首尾两档。首次绘图直接终态，普通读值的“看当天”与读值同一行，大字分行。
- StatusChip 的可点击Material/InkWell最小44，12圆角，选中中性surface与文字/边界；ChipRow提供共用中性轨道并保持自然换行。
- MileafNavBar改实色，保留四项、选中位置标记和回调。导航文字12/16，栏高按实际缩放增加。
- BatteryArc 的大字中心读数移到弧外，自然增加高度，避免固定小弧截字。充电详情已有相邻精确SOC，因此以showLabel=false只画弧并保留完整语义。
- MileafDataRow 的尾部改可换行Wrap，支持大字金额/徽标自然重排。
- MileafSheetFrame在可用高度小于400时将标题与内容放入同一个滚动流，保持关闭按钮与提交可达。费用请求/恢复状态机保持原调用。
