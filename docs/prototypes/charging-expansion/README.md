## 实际可操作的部分

- 近30/7日切换；A图表的入电/费用/均价/次数切换、点日/前后日读数；完整方案可进入结束日记录。自定义只说明正式规则，没有实现任意日期日历。
- 全部记录视图：完整方案按整个合成区间搜索地点、AC/DC/未知筛选，按时间/有效入电均价/记录时长排序，分批加载；匹配数/匹配集摘要随查询变化，不只筛初始6条。
- 点地点卡、C示意图标记进入地点记录；仅现有接口模式的C只显示本页地点，点标记打开其中最近一次，不冒充全量地点聚合。
- 点记录进入单次回顾；功率/电量可切，完整方案增加电压/电流/室外温度/额定续航，以及按时间或SOC查看；点图、拖动、前后点/图表方向键读数。原型尚未实现加热离散轨道、理想续航切换和任意SOC区间配置，它们是接口文档中的后续要求。
- 帮助层解释费用、分类、跨夜、原始采样、20–80和能量；原始明细可展开。其他主导航说明本轮边界。
- 浅深色、CSS字号100/200%、币种已选/未配，正常/缺失/无记录/进行中/旧快照/统计失败/序列失败；重试回到固定正常样例。不是正式网络重试验收。
