01 / 五秒内有主线

结果先行，证据紧随。

只突出一个主数字。比较是自己的同进度，副读数交代电耗与已知支出；主图在首屏完整出现。

02 / 内容有层级

不是把更多卡片摆进来。

节奏、条件、账目、长期分章。手机内可以切专题、选点、点日、点分组和地点；右侧预览展示能耗专题。

03 / 结论有边界

看见数据，也看见可信程度。

覆盖贴近数值，温度只谈关联，续航估计不叫健康分。失败、基期0、小样本时退回原值。
