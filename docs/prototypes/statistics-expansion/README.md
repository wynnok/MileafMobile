## 实际可操作与未实现部分

- 本月/本周：截至固定10/28 19:10，周一为起点；其他区间只解释正式本年/自定义/IANA/730天规则，原型不实现任意日期选择或全年数据。
- 首页里程/净电耗/估算能量/次数切换；补能页入电/已知支出/有效均价/次数切换；点柱/点或前后按钮读原值，开启/关闭同进度参照。原型只为里程/净电耗提供参照曲线。
- 总览、能耗、补能、长期专题；长期显式为2026.05–10的6月窗口，不伪装成本月结果。长期/停放模型仅完整方案有，缺样本有降级。
- 点日历或图表的当天打开行程及结束日充电；点距离/温度组进入完整合成匹配集，再点行程看证据；点AC/DC/未知、地点看对应合成记录。图中没有真实地图/轨迹，正式下钻复用既有详情。
- 净毛电耗比较、原始日桶表、指标/口径帮助、费用覆盖和地点账目可阅读。原型未逐项画网侧均价/分类时长的独立图、P90/星期分布、CH06小时热图、12月长期切换；它们的范围/优先级在方案与接口文档中，没有假按钮冒充已完成。
- 浅深色、CSS文字200%、币种已选/未知，正常/字段缺失/无记录/基期0/参照失败/补能失败/样本不足/旧快照；重试回到固定正常样例。它不是生产请求/重试/缓存/切车竞态验收。

## 保存与验证边界

本轮遵从用户「先方案与原型」及implement的本地提交要求，只提交方案、一次性原型及证据到当前 `codex/mileaf-v1`；不将脚本接入Flutter生产资源/路由，不修改已发布Spec、推送、部署或关票。选择后的正式实现需要重写，保留所选设计决定，原型后续可按仓库既有方式保存为primary source。

浏览器检查不代表Flutter/真机/真实站点验收。原有Flutter静态分析与完整回归结果单列在验证记录；本轮没有正式App新功能可做TDD，因此不为一次性原型新增测试依赖或实现镜像测试。待确认正式切片后按既有App/可控HTTP边界测试先行。
