## 可以实际操作的内容

- **找记录**：近30日/近7日切换；日图点读或前后日按钮；「看当天」筛选与清除；分批加载。自定义日期入口说明正式日历行为，原型仅有两组固定区间，未实现任意日期选择器。
- **看一次出行**：点记录联动右侧详情；手机版直接进入详情，可返回列表。C的端点簇可点开该终点本页最近的一趟，数字与列表对应；它是本页端点示意，不是全历史地图。
- **看过程**：速度/电量/海拔切换；图上点按/拖动；前后点或图上的左右方向键选点；地图标记与曲线读数使用同一采样。可打开上下对齐的电量对照图。方向键在输入框/下拉框/图表内有各自语义，不切换方案。
- **读依据**：期间说明、个人历史参考说明、采样说明和原始明细可打开；其他主导航说明本轮评审边界。
- **扩展预览**：同起终点的同向历史样本、常走路线卡、全查询地点搜索、功率/回收、速度区间时长、爬升/下降。搜索需按回车或右箭头提交，匹配整个合成期间集合，并更新匹配集摘要；不是当前已载入6条的本地筛选。
- **状态**：正常、部分缺失、无记录、进行中、旧快照/重试、地图失败/重试。外观浅/深与CSS字号100%/200%可切换，不代表原生字体与辅助功能验收。

- 个人参考154Wh/km为另一个固定合成统计，参照窗口取所选行程开始日前30个完整本地日。不是当前列表期间，不含当前行程，不叫同路线对照。扩展预览的同向8次中位数156、范围142–181是独立有效历史样本示意；不是当前分组记录的平均。
- 功率曲线围绕0显示，回收0.84kWh、回收峰值32kW、爬升148m/下降132m为独立合成服务端结果。速度时长总计与所选行程时长一致，未覆盖与质量规则正式实施前另定；不积分抽样、不按采样点数算时间占比，不把低速/静止叫拥堵。
- 缺失状态保留里程/次数，本次能量、电耗、到达SOC与部分采样为空；不补零。进行中状态从期间完成统计中排除最新一趟，隐藏最终结果/比较/未来时长聚合。旧快照09:10早于固定时钟、晚于最新完成记录，时间自洽。
