## 操作与样例边界

- 范围：现有API可支持的指标 / 完整愿景。后者有停车变化、电量历史、长期续航入口与费用完整度示例，全部标识为待建能力。
- 状态：正常、部分缺失、本期无记录、旧快照/重试；外观：浅/深；字号100%/200%。CSS字号放大仅用于排版检查，不代表系统字体或原生辅助功能通过。
- 本月/近7天切换使用不同的固定合成子集，不是实际区间请求；净电耗、费用和均价按样例保持数值自洽。源文件内聚合只为生成固定合成样例，**正式App总计和比率必须取服务端结果**。
- 主数可切换图表；日桶可点击读数、前后读数；记录与统计入口可往返。下钻只证明路径可理解，示例详情不重做现有正式地图/曲线。车辆/设置为说明入口，不能切真实车或改设置。
- 同期对比基期166Wh/km为合成值。当前月对比9月同日截止时刻，近7天对比前一同长日历窗口；真实实现需增加stats区间查询。无样本不显示差异。未用比较结果自动评价驾驶或解释原因。
- 样例快照固定在2026-10-26 18:40 Asia/Shanghai；本月里程1198.6km、估算驾驶消耗189.3kWh、净电耗158Wh/km，充入234.7kWh、已知费用186.4CNY。9次充电中8次费用已知，含一次真实0费用；现有API视图不展示覆盖数。
- AC118、DC96kWh；已知分类DC占比44.9%。分类不完整，不归一化为全部补能，不显示补算的未知能量。费用未知会话能量24kWh，因此已知费用均价0.88CNY/kWh。
- 主图包括日历零值与缺失；电耗缺失不补0。停放例为8小时20分内采样80%→79%，不是损耗计量或原因诊断。24小时电量线是合成采样，缺口断开，0–100%尺度，不是接通的真实历史接口。
