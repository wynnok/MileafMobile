# 统计扩展方案：让一段时间的用车有结论

2026-10-28。状态：**方案与原型待评审，尚未确认实施范围**。本轮响应用户「先出方案、更新原型图，不要直接动手」；只交付设计资产与接口交接，不修改正式 Flutter、已发布 Spec 或工单验收状态。

## 建议的产品方向

推荐 A「用车洞察」：**先看这段时间的变化，再解释用车结构，最后进入可核查的记录。** 统计首页回答「我怎样使用这辆车」，能耗、补能、长期三个专题回答下一层问题。它与概览的「现在与近况」、行程的「某次出行」、充电的「某次补能」分工明确。

如果我是车主，最想知道的是：开了多少、单位里程用了多少电、和自己以前相比怎样；充电的钱花在哪里、记录是否齐全；短途/长途、气温等条件下呈现什么差别；停着的电量变化与长期续航是否值得继续观察。最高速度、最大功率有查询价值，但不应抢占首页，也不应被做成鼓励追逐极值的成绩。

这里的优先级是产品判断，尚不是用户选择。首屏不输出虚构的省钱建议、健康评分或异常诊断。

## 三个可比较的结构

| 方向 | 第一眼看什么 | 后续阅读 | 判断 |
| --- | --- | --- | --- |
| **A 用车洞察（推荐）** | 一句跨期结果、一个主数字、里程主图 | 用车节奏 → 能耗条件 → 补能结构 → 长期观察 | 大部分车主的默认入口；结论和证据距离短 |
| B 效率透镜 | 净电耗主数字、气温分组曲线 | 短长途分组 → 每日净/毛比较 → 行程证据 | 适合深入理解电耗，作为能耗专题更合适 |
| C 用车年历 | 月历热图、活跃日与里程 | 点日看记录 → 年内月趋势 → 行程分布 | 回顾感强，适合查某一天；不能单独承担全部统计 |

三者都保留湖畔的绿白/深绿体系。差异在信息主次、图形和阅读路径，不靠换色制造选项。建议 A 做默认，吸收 B 的分析方式与 C 的日历入口，不增加三个主导航。

## A 的信息架构与视觉层次

360×800、100%字号的首屏顺序：车辆/周期 → 总览/能耗/补能/长期 → 结论与主数字 → 有刻度和选点的完整主图。只让里程成为最大数字；净电耗与已知支出是两项副读数。费用覆盖紧贴费用，简短估算口径紧贴电耗。上期比较用琥珀虚线/空心点，本期用绿柱/实线；同图不混单位、不使用双轴。

默认结论在完整方案中采用固定、可解释规则：里程变化与净电耗变化均可比时，描述方向和数值，不把「多开」当成好坏；电耗下降只描述下降，不声称驾驶技术改善。缺参照、基期为零、字段缺失或任一侧失败时，退回「本期用车回顾」与可用原值。首轮不做 AI 生成分析、动态信息排序或跨车排名。

首页往下是连续章节，而非十几个同等大小的数字卡：

1. **用车节奏**：日历热图识别高频/集中用车；活跃日、驾驶记录时长、单程中位数帮助建立尺度。点日进入当日证据；热图色阶有单位，未到日期留空。
2. **电耗与条件**：一张按室外均温分组的加权电耗图，附有效趟数和里程；再看短/中/长途分组。标题只说「不同条件下的记录」，不说「气温导致节能」。净/毛口径独立比较，避免把差额称为停放损耗。
3. **补能账目**：AC/DC/未知的绝对能量条形；已知支出、费用覆盖、有效入电均价、充电记录时长；地点前几名展示金额和入电，而不是空泛的「最佳充电站」。点分类/地点进入相同筛选条件下的既有账本。
4. **长期观察**：两张专题入口，展示满电等效额定续航月趋势与可观测停放窗口变化。首页不放「电池健康98%」仪表盘。点入再看方法、样本、缺口与记录。

顶部专题不是重复页面：能耗页把条件图和分组提升为主图；补能页把账目、费用/能量/次数/均价时间图与地点提升；长期页显式切换6个月/12个月观察窗口，不能暗中沿用本月标题显示半年数据。原有驾驶/充电全部指标继续可到达，最高速度和原始桶明细收在「全部指标与口径」。

## 指标覆盖与能力清单

「现有」指本地已冻结API/实现，**不代表真实站点已部署**；「新增」必须先补服务端，不能由手机遍历分页或下载所有 positions 推导。

| ST01 这期用了多少？ | 里程主数字；行程数/估算净能量/净电耗；按日/月趋势 | 现有 driving stats totals/buckets；全区间总比率取服务端，不平均桶 |
| ST02 相比自己以前怎样？ | 同尺度参照趋势；里程%与电耗绝对差/相对% | 两次现有stats可展示原值；可靠比较状态、覆盖与查询回显拟新增。月为上月同期、年为去年同期、周为上周同进度；不足的日期不强行配对；自定义为之前等本地日数、同日内进度窗口；跨DST保持本地日历语义 |
| ST03 车怎样融入生活？ | 日历热图；活跃日、驾驶小时、每活跃日里程、单程距离/时长中位数及P90、短中长途分布 | 日热图可用现有日桶；活跃日全范围汇总、时长/分位数/分布新增。不能用年视图的月桶推活跃天数，不能从中位数再聚合 |

| ST05 电与钱花在哪里？ | 充入量、已知支出、两类有效均价、覆盖、分类能量与时长、地点排行/下钻 | **现有0.2 CH01–CH03**；本方案复用，不重新要求造接口。分类未知不是AC；DC占比保留已知分类分母 |

## 科学、直觉与缺失规则

- **比较同样的进度**：本月截至10/28 19:10，对比9/1–9/28 19:10，不拿28天和完整30天算增减。比较日期、IANA时区和未结束桶可见。原型固定时钟2026-10-28 19:10 Asia/Shanghai；正式日期规则须经DST/月长差异测试。
- **不要制造能量守恒图**：充入电池、估算行驶能量、电网侧量是三种事实，归期与库存SOC也不同。不能画「充电=驾驶+停放+损耗」桑基图，也不能把毛减净自动叫待机耗能。
- **不把费用覆盖掩盖掉**：已知支出不叫总用车成本；0元是已知免费，null是未记。有效均价采用配对同批会话。期间支出/里程即使可算，也只能叫「期间支出折算」，不是车辆真实每百公里成本，因此不作为首页主指标。
- **加权且可解释**：分组电耗用同一批有效行程的总能量/总距离；覆盖、最小样本门槛与排除数同时返回。不在图上平均不同里程行程的电耗，不用稀疏组给强结论。不把SOC百分点写成相对百分比。
- **视觉不夸大**：里程/费用柱图从0起；电耗/长期范围折线允许局部轴但必须显示刻度；未知值断开、孤立点可见、负值保留。浅深色共用语义且有线型/标签，不靠红绿区分好坏。图表有选点、前后点、读数明细，文字放大时重排而不裁数字。
- **时间和质量有自己的位置**：查询校验时间不是采样时间。无记录显示0与无记录；有记录字段全缺失显示—与原因。基期0不输出∞%；统计/参照/专题各自失败和重试，不用一个成功掩盖另一个失败。首次记录不足不展示伪健康分。
