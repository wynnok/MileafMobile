## 供确认的建议与开放项

“待确认”不是已接受的实现决定。to-spec 主要负责综合，不应依赖进入该阶段后重新做需求访谈。
建议用户在授权进入 to-spec 时确认以下推荐方向，或给出替代方案。

| 项目 | 当前建议 | 进入 spec 的处理方式 |
| --- | --- | --- |
| 导航与视觉 | 概览/行程/充电/统计四入口，车辆在顶部切换；清晰、克制的记录风格 | 确认页面与交互文档即可，不要求现在做高保真稿 |
| 首次初始化 | App 提供显式“首次设置站点口令”入口，不通过 401 自动猜测 | 需确认，另一方案是管理员在 App 外完成 setup |
| 网络接入 | 公网 HTTPS；是否允许用户明确选择的受信任私网 HTTP 待定 | 需确认目标场景，并在实现前验证两端平台限制；不关闭证书校验 |
| 地图 | 首版保留轨迹与可缩放底图、加载失败时可读其他数据 | 需明确主要使用地区与是否接受第三方地图服务；供应商/坐标方案未决时，相关实现不能标 ready-for-agent |
| 时间、单位 | 跟随设备 IANA 时区，默认公制；本地设置不改后端 | 需确认是否首版开放英制切换，及旅行换时区时的显示规则 |
| 币种 | 单站点本地配置币种，不换汇、不按设备地区猜测 | 需确认；另一方案是不显示币种符号并明确“币种未配置” |
| 列表与统计默认值 | 列表近 30 天，统计本月；支持本周/本年/自定义 | 确认；统计不承诺跨 730 天的自动合并 |
| 缓存与刷新 | 会话期内存缓存、手动刷新与前台校验，不持久保存离线业务数据 | 确认即可；后台轮询不在首版 |
| 语言与主题 | 中文优先，跟随系统浅/深色 | 英文翻译、主题手动切换是否属于首版待确认 |
| 支持与验收 | 手机优先，平台最低版本和参考设备未指定 | spec 固定支持范围及性能测量条件，不能套用服务端测试结果 |

若某项未决定，可以在 spec 中明确列为依赖或排除范围；但不能把仍依赖产品决定的实施工单
标为 ready-for-agent。地图供应商、网络策略和币种影响首版可交付性，优先确认。

## 建议的技术边界（未冻结库或架构）

- 一个 API 访问边界：管理服务地址、Bearer、超时、错误 envelope 和 ETag，页面不拼接不同口径。
- 一个业务读取接口供页面使用；HTTP、DTO 解码和页面展示分开，支持用固定 API 响应驱动完整用户路径。
- 安全存储仅保存会话；普通设置保存选车、单位、时区等非敏感偏好；不保存明文站点口令。
- 所有请求/结果都归属站点、会话、车辆和查询条件，切换后防止迟到响应污染页面。
- 图表和底图独立于详情指标加载；第三方失败不遮蔽已有结果。
- 不在此阶段决定状态管理、路由、网络、图表或地图的具体 Flutter 包，不为未来功能加抽象。
- 后端契约固定与 Dart 客户端生成属于后续工作，当前没有可发布的移动端 SDK 或锁定契约快照。

## to-spec 应确认的测试边界

推荐以“用户通过 App 完成操作并看到正确结果”为最高公共边界，
用可控 HTTP 响应驱动页面流程，验证外部行为，而不是测试状态管理的内部调用。
平台安全存储和地图 SDK 无法完全由同一边界覆盖，补少量真机验证。
这只是测试边界草案；调用 to-spec 后，按其流程先与用户确认测试边界，再发布正式 spec。

| 场景 | 可观察的通过条件 |
| --- | --- |
| 接入与登录 | 合法地址登录成功；错误口令、409 初始化冲突、429 限流有明确反馈；口令不落盘 |
| 会话恢复与过期 | 重启可恢复；过期/撤销导致的 401 回登录；本地退出清除本地会话 |
| 多车与并发 | 快速切车后所有 tab 只显示当前车数据，旧请求不会覆盖新车 |
| 概览与新鲜度 | 0、null、休眠快照及最近采样时间正确区分；不暗示实时控制 |
| 列表与筛选 | cursor 翻页不重复漏项；变更筛选重置分页；失败保留已加载内容 |
| 详情与曲线 | 空序列、单点、缺失值、进行中及部分请求失败不崩溃、不伪造数据 |
| 指标口径 | 净/毛电耗与两类能量不混淆；totals 使用服务端值；未知 AC/DC 不归入已知分类 |
| 时间与单位 | 本地日界、周一起始、夏令时和公英制只换算一次；充电开始/结束归期差异有说明 |
| HTTP 条件请求 | 304 复用对应结果；跨车、跨站点、跨会话不复用错误缓存 |
| 平台与地图 | 两端验证安全存储、连接策略、坐标对齐、底图失败降级、返回手势及大字体 |
| 性能与对账 | 在固定设备/网络/数据集测量；与同车同区间的后端及 Grafana 已知口径核对 |

移动端当前没有测试先例；可参考后端 test_auth、test_summary、test_resource_lists、
test_resource_series、test_stats 的输入场景，但不复制其内部 SQL 测试。
本轮不新增测试或声称这些后端测试已通过。
