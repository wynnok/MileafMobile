# 行笺移动端：需求澄清与实施交接

更新：2026-10-25。本文件替代 2026-10-22 的 to-spec 前交接清单；Spec #1 和 #2–#17 已发布，不能继续按“尚未发布、等待 to-spec”执行。

## 已确认的产品方向

行笺以移动端为载体，美观、直观、体验良好地尽可能展示 TeslaMate 数据；参考 Grafana 指标，不要求逐项相同或迁移桌面布局。图表、地图和关键数字是概览、详情、统计的主要内容，文字和明细辅助理解。此方向来自用户本轮明确重申，不是待确认建议。

| 基线 | 当前决定与依据 |
| --- | --- |
| 指标覆盖 | [可视化需求 V01–V08](visualization-requirements.md)为首版最低内容；G01–G08 记录 Grafana 参考主题、缺口与后续候选，不以当前 API 或旧页面为长期产品上限 |
| 范围与导航 | 单站点多车辆；概览/行程/充电/统计四入口，顶部切车，详情下钻；连接、显式初始化和设置仍属首版 |
| 数据与安全 | Flutter Android/iOS，仅经 Mileaf Server API 读业务数据；不控制车辆、不接 Tesla 凭据、不改只读外部仓库或生产库 |
| 接入与会话 | 公网 HTTPS；受信任私网 HTTP 逐站点授权；显式 setup、无 refresh、平台安全存储、本地退出和候选连接原子替换，沿用正式 Spec |
| 展示规则 | 中文、公制、设备 IANA 时区、站点币种标签、系统浅深色；不新增英制/手动时区/手动主题 |
| 日期与缓存 | 列表近 30 个日历日；统计本月默认并支持周/年/自定义，730 天限制；会话期内存和 ETag、前台当前页校验，无后台轮询 |
| 平台与地图 | Android API 24/iOS 15；真实底图、源 CRS、许可和大陆双端网络仍按原验证条件处理，构建/候选代码不能代替验收 |

3. [Spec 本地镜像](../specs/mobile-v1.md)及正式 [Spec #1](https://github.com/wynnok/MileafMobile/issues/1)使用相同修订正文；#8–#17 的相关页面/地图/性能/集成票同步本轮新增验收，不新建一套并行规格。
4. [验收记录](../implementation/acceptance.md)区分已有数据闭环证据、尚未实现的可视化要求和外部待验；#8–#17 保持开放，原生依赖边及历史证据保留。

## 下一阶段实施顺序与完成条件

| 阶段 | 必需交付 | 不足以证明完成的证据 |
| --- | --- | --- |
| 可视方案 | 概览、两类统计、两种详情和两类记录卡片的代表性渲染/原型；有起伏/零/null 的合成数据；记录具体视觉方案的用户评审 | 只补文字需求、只列图表库、纯文字线框或任意占位图 |
| 页面实现 | 依 V01–V08 和对应工单交付可交互图表、地图及记录卡片；概览补本月 stats 趋势；保留日期/会话/错误隔离 | 已接 API、每桶一个展开文字条目、只有缩略装饰图或图表标题 |
| 自动化与渲染 | App/HTTP 覆盖指标切换/选点/单位/时间/空值；固定数据核对实际绘图区、图例、刻度、遮挡，保存浅深色和大字体证据 | 仅查找文字、构建成功或原有测试通过 |
| 外部体验与数据 | 双端手势/读屏/真实底图与真实站点对账；性能起止包含默认主图实际可读 | 桌面行为测试、后端耗时、仅 summary 就绪、无来源的美观/流畅结论 |

已有认证、契约、分页和时区代码可复用；页面视觉按新基线逐项评估并实现，不能在文档里直接宣称已经满足。用户已允许代码/自动化先行，真机/地图/真实站点条件不足时记录待验，不关闭 Ticket。

本轮只完成文档澄清、正式 Spec/相关工单同步和文档验证；不实现 App、不安装工具或依赖、不修改外部仓库、不推送或部署。后续仍需交付可视方案，不能把本轮文档澄清当作视觉原型已通过。
