# 行笺移动端：页面与交互

日期：2026-10-22；2026-10-25 修订。状态：与正式 Spec 配套的页面体验基线，替代原“关键数字优先、曲线放下钻”的建议。
页面指标、图表与验收以[数据可视化需求基线](visualization-requirements.md)为准；本文件规定信息层级，具体视觉稿尚待评审。

## 信息架构

底部四个入口：**概览、行程、充电、统计**。
车辆选择位于业务页面顶部；连接和展示设置从概览的设置入口进入，
不增加承载少量配置的第五个 tab。详情作为列表的下一级页面。

首次使用进入服务连接；有有效会话则恢复上次车辆并进入概览。
只有一辆车时自动选择；无车辆时显示空状态和站点检查入口。
站点切换意味着替换当前连接，不是多站点管理。

## 接入与会话

| 阶段 | 规定行为 | 当前后端约束 |
| --- | --- | --- |
| 服务连接 | 输入地址，明确保留反代路径前缀，再检测健康 | health 检查数据库可达性；失败不一定代表 URL 填错 |
| 登录 | 输入站点访问口令，成功后保存 token 与到期时间 | login 返回 token、expires_at，无刷新 token |
| 首次初始化 | 提供用户明确选择的“首次设置站点口令”入口 | 无匿名 initialized 状态；不能把登录 401 自动当成未初始化 |
| 恢复 | 从平台安全存储恢复会话；401 时回到登录 | token 30 天有效，可能因服务重置或 token 数量上限提前失效 |
| 退出 | 清除本地 token 和相关缓存，说明是退出此设备 | 当前无服务端 logout/revoke 端点 |
| 连接失败 | 保留输入，区分网络不可达、数据库不可达、登录失败、限流 | 使用 HTTP 状态与 error.code，不能只解析 message |

不保存明文口令，不记录 token 或带凭据的请求。新地址完成校验、登录前不覆盖可用旧连接；
旧站点 token 不发送到新地址。公网 HTTPS；受信任私网 HTTP 必须逐站点显式授权，
不得以关闭证书校验解决自签证书或连接问题；细节沿用正式 Spec。

## 页面内容与优先级

| 页面 | 首要视觉内容 | 明细/补充内容 | 交互 |
| --- | --- | --- | --- |
| 概览 V01 | 状态/电量图形、续航与关键结果卡片、本月每日里程柱图 | 最近行程/充电、里程表、固件、分开的数据时间 | 下拉刷新；点记录下钻；主趋势与 summary 独立加载，功率有值时显示 |
| 行程列表 V02 | 日期分组记录卡片，地点与距离/时长/净电耗分层 | 时间、进行中及缺失提示 | 默认近 30 天；日期筛选、分页、点入详情，不预取每条曲线 |
| 行程详情 V03 | 简短摘要后进入轨迹地图、速度/电量/海拔时间曲线 | 能量、速度/功率、内外温度均值、起终点电量及地点时间 | 默认速度，可切指标、点按/拖动和辅助选点；地图缩放；独立重试 |
| 充电列表 V04 | 地点、同尺度起止电量区间图、能量和费用卡片 | 时间、AC/DC/未知、时长、进行中 | 默认近 30 天；日期筛选、分页；缺失端点不伪造区间 |
| 充电详情 V05 | 简短摘要后进入功率/电量曲线，起止电量图、两类能量比较 | 费用、温度均值、类型、时长、已有相数信息 | 默认功率，可切电量并读数；能量不相加或推导损耗率 |
| 驾驶统计 V06 | 默认里程时间柱图；行程数/能量/最高速度可切；净毛电耗同单位折线比较 | 服务端 totals 卡片及逐桶明细 | 本月默认，周/年/自定义；切指标不换区间，图表可读桶值 |
| 充电统计 V07–V08 | 默认能量时间柱图，可切会话数；费用/均价时间图；AC/DC 分组与时间比较 | totals 卡片、已知分类 DC 占比、费用完整性短提示 | 沿用统计区间；不同单位分图；未知不归 AC，不画虚假的全部能量饼图 |
| 车辆选择 | 名称、车型、VIN 后四位，当前选中项 | 电量和记录时间 | 未命名时用车型和后四位区分，不展示完整 VIN |
| 设置 | 当前服务地址、重新登录/替换连接、本地退出 | 服务版本与 tested 状态、站点币种；公制/设备时区/系统主题说明 | 币种标签仅在本地生效，不修改 TeslaMate；首版不增英制/手动时区/主题切换 |

统计分桶：周/月用 day，年用 month，自定义≤31 本地日用 day、32–180 日用 week、其余 month，单次 UTC 跨度≤730×24 小时。
UI 选择的是本地日历区间；传入统一 IANA 时区与转换后的 UTC 半开区间。
列表和统计在边界处的记录数量可能不同：充电列表按开始时间，充电统计按结束时间。

## 数据与异步状态

| 情况 | 必须保留的语义 | 建议呈现 |
| --- | --- | --- |
| 首次加载 | 没有结果，不能先显示 0 | 骨架屏或加载指示 |
| 无记录 | 正常成功响应为空 | 空状态；时间筛选后可扩大区间 |
| 字段 null | 未知或上游未回填，不等于 0 | “—”并按需说明；不将曲线 null 点补零 |
| 进行中 | 结束时间和最终指标可能为空 | “进行中”，不伪造结束时间或最终时长 |
| 刷新失败 | 已展示结果未必无效 | 保留旧结果并标明快照与失败，允许重试 |
| 翻页失败 | 已加载页面继续可用 | 列表底部重试，不重置为整屏错误 |
| 详情部分失败 | 明细、序列、底图是独立结果 | 已成功区域继续展示，不被一项失败覆盖 |
| 数据长时间未采样 | 可能是车辆休眠，不能推断 TeslaMate 故障 | 显示实际采样时间，不无依据使用故障红色告警 |
| 快速切车/筛选 | 较早请求可能最后完成 | 仅接受匹配当前车与查询条件的结果，不串车、不串区间 |
| 304 | 没有新响应体，不是空数据 | 复用同站点、同会话、同路径和查询的缓存；无对应缓存不能当成功空响应 |

首版仅保留会话期内存结果与 ETag 缓存，不增加持久化离线数据库。
手动刷新和回到前台按缓存有效期重新校验，不做后台轮询或秒级定时器。
列表刷新、车辆切换、筛选变更均重置 cursor；分页结束以 next_cursor=null 为准。

## 地图与图表的边界

- 轨迹来自行程序列中的 lat/lon，是服务端采样结果，不是导航路线。
- 默认请求所需字段和 200 点；最大 1000 点。不能承诺还原每个转弯或每个峰值。
- 无坐标、单点和底图加载失败时仍可阅读文字指标与曲线。
- null 断线，不补点补零；无 gap 标记时不按固定间隔推断断采，连线仅表示采样示意。
- 地图交付沿用正式 Spec 和[地图验证记录](../implementation/map-candidate.md)：必须有合规真实底图、源坐标核准及中国大陆双端可用证据；候选接入不等于供应商/坐标已验收。
- App 展示既有轨迹不需要手机 GPS 定位权限，首版不申请此权限。
- 地图底图服务可能接收可见区域请求，不能将后端“不外联上报”扩展成整个 App 无外联承诺。

## 视觉交付与平台基线

中文界面、跟随系统浅深色，Android API 24/iOS 15，手机纵向优先，沿用正式 Spec。
默认字号概览首屏露出实际趋势，统计简短总计后可见主图，详情摘要后进入地图/曲线；长口径说明放帮助层，重要缺失提示留在图旁。
先评审代表页面可视原型，再对实际页面做浅深色、360 宽/200% 字号及手势验收；图表有坐标/单位/图例和等价读数。
图表库、配色细节与像素稿由实施方在本基线内设计，不把“图表为主、美观易读”重新列为待确认方向，也不以逐行文字及进度条满足视觉交付。
