## 决定与来源

采用近况图形/关键卡片 → 完整趋势 → 最近记录的层级。浅色采用柔和绿白底、深色采用深绿底；主系列为绿色，比较系列为琥珀色，图例和线型/点形同时区分系列。卡片保持统一圆角、边界和留白，数字与单位清晰分层。系统字体放大时纵向重排，优先保留图形与等价读数。

原型 primary source 保存在本地分支 `codex/mobile-visual-prototype`，提交 `a965dc9`；入口为该提交中的 `docs/prototypes/mobile-visualization/README.md`，A方案的七类浅深色渲染在同目录 `renders/A-*-light.jpg`、`A-*-dark.jpg`。原型合成数据、示意底图及浏览器渲染不是正式Flutter/地图/真机验收证据。正式分支只落地选定方案，不合入原型脚本、B/C方向或评审切换器。

## 页面与实现约束

- 概览：电量比例图、续航/状态卡片、今日/本月关键结果与本月每日里程完整时间图；summary与stats独立加载、错误和重试。
- 记录：本地日期分组、地点和主指标分层，充电起止电量在同一0–100%尺度展示；不预取每条序列、不从分页补算区间总计。
- 详情：简短摘要后是地图/默认曲线，指标切换和读数明显；次级指标在图后或可展开区域，所有原有数据和恢复入口仍可到达。
- 统计：简短totals之后进入完整主图；驾驶包含里程/次数/能量/最高速度及独立净毛电耗比较；充电包含能量/次数/费用/均价及AC/DC绝对值/时间比较。总计与比率均使用服务端原值。
- 图表：真实时间坐标、可读轴/单位、选点/拖动/前后读数及辅助功能；null断线，孤立已知点可见，真实0和负值保留。比较图同单位同尺度，不默认双轴或归一为全部能量。
- 重要缺失/口径提示短而可见，长说明进入帮助层。费用无默认币种，不补未知值或推导unknown_energy/充电损耗。

共用图表与展示组件属于本轮多个页面实际共同需要的行为；不引入新的图表依赖、图表插件架构或后端能力。保留现有API、会话、条件缓存、日历及地图安全边界。
