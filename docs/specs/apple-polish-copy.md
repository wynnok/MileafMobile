# 行笺文案与术语规范

版本 1.0，日期 2026-11-16，状态为 **accepted**（对应精修规格 PD09，用户 2026-11-16 确认）。本文是[精修规格](apple-polish.md)的文案部分，规则编号 CP01–CP12，日期格式编号 DF1–DF9。对照表中的「建议」随所属页面票实施；表中标注「需用户确认」的条目与 CP12 冻结文案仍须单独确认。

适用范围：所有用户可见文字、读屏标签、tooltip、错误与空状态、图表读数与轴标签。不适用：日志、调试输出、测试名称、服务端契约字段。

## CP01 语气

- 平实、确定、简短。用车主的话，不用数据库的话；先说结果，再说限定。
- 称呼用「你」，不用「您」；不用感叹号；不写「请」开头的命令句，除非是安全或不可逆操作的提醒。
- 标题与标签是名词短语，2–6 字为宜，最长 8 字，不带句号；脚注、说明、错误是完整句，以「。」结尾。
- 不把期间名写进标题（期间控件已经写了）；不在标题里放单位（单位跟随数值）。

## CP03 数字与单位

- 千分位：`1,198.6`；小数位沿 `number_format.dart` 与各字段现有业务精度，本轮不改精度。精度调整只作为候选另行确认（见文末）。
- 数字与单位之间一个空格：`60.0 km`、`46 分钟`、`52 趟`。`%`、`°C` 紧贴：`68%`、`−5°C`；币种符号紧贴在前：`¥186.4`；单价写 `¥0.87/kWh`。
- 负数用真负号 `−`（U+2212）；增减在句子里写「多 / 少 / 高 / 低」，不用 `↑ ↓` 符号代替。
- 时长：小于 60 分钟写「46 分钟」；60 分钟及以上写「1 小时 12 分钟」，整点写「2 小时」；24 小时及以上写「2 天 3 小时」。不写 `5h10`、`13h18`、`798 分钟`。
- 单位不当标签：「今日 km」「估算 kWh」改为标签「今日里程」「估算耗电」，单位跟在数值后。
- 缺失值显示「—」，配一句原因；未知不等于 0，0 不写成「—」。
- 电量区间写 `18% → 82%`，箭头两侧各一空格；路线写 `家 → 公司`。箭头只用于路线与区间。

## CP04 日期与时间

所有日期均为站点日历的本地时间，格式化只做字符串化，不改时区与归期逻辑（S04）。由 AP06 的共享格式化器统一输出，页面不得自拼。

| 编号 | 场景 | 格式 | 例 |
| --- | --- | --- | --- |
| DF1 | 单日 | M月D日；非今年加年 | 10月26日；2025年12月28日 |
| DF2 | 记录分组标题 | 今天 / 昨天 / M月D日 周X | 今天；10月24日 周六 |
| DF3 | 日期区间 | 同月 M月D日–D日；跨月 M月D日–M月D日；跨年两端都带年 | 10月1日–26日；9月27日–10月26日；2025年12月28日–2026年1月3日 |
| DF4 | 时间 | HH:mm；时间段 HH:mm–HH:mm；跨日写全 | 16:05；16:05–16:51；10月26日 23:40–10月27日 00:15 |
| DF5 | 日期加时间 | DF1 + 空格 + DF4 | 10月26日 16:05 |
| DF6 | 月份 | M月；非今年加年；月区间 M月–M月 | 10月；2025年10月；5月–10月 |
| DF7 | 相对时间（数据新鲜度） | 刚刚（<1 分钟）、N 分钟前（<60）、今天 HH:mm、昨天 HH:mm，其余 DF5 | 2 分钟前 |
| DF8 | 精确时间（仅「关于这些数据」与技术详情） | YYYY-MM-DD HH:mm:ss，可复制 | 2026-10-26 16:05:00 |
| DF9 | 图轴 | 日级：同一月内首刻度 M月D日、其余 D日，跨月时每月第一个刻度写 M月D日；周级（自定义 32–180 天按周分桶）：每桶首日 M月D日；月级：M月；时间级：HH:mm | 10月1日、14日、26日；9月1日、9月8日；5月、8月、10月；06:10 |

- 区间分隔符用连接号 `–`（U+2013），两侧不加空格；不再使用 `—`、`至`、`/`、`.` 作日期分隔。读屏读法为「10月1日至26日」。
- 自定义区间包含结束当天，在日期弹层脚注写一次「包含结束当天」，不在每处重复「含首尾」。
- 「今天」「昨天」按站点日历判断，跨 DST 日沿现有日界计算。

## CP05 标题

- 区块标题：名词（「本期账目」「最近记录」「用车专题」「充电地点」）。
- 卡片标题：名词（「每日里程」「充电过程」「电量计量」）。
- 详情身份标题：记录本身（路线、地点），不写「行程 #17」。
- 不用诗化或口语化标题：「最近的路」「这一次的账」「我的补能方式」「一条有参照的变化」「继续」「自己的地点账目」全部改名（见对照表）。

## CP06 操作

- 动词 + 对象，2–6 字：「查看当天」「查看全部」「补录费用」「重试」「加载更多行程」「应用」。
- 同一位置的同类操作用同一个词：重试统一「重试」，读屏标签补全对象（「重试读取驾驶数据」）。
- 图标按钮必须有 tooltip 与语义标签：刷新「刷新概览」、步进「上一个数据点」「下一个数据点」、温度组「上一组」「下一组」、月份「上个月」「下个月」。
- 下钻行以「查看」开头，行尾箭头，不在文字末尾附「›」字符。

## CP07 状态与错误

由 AP06 在 `lib/src/copy/messages.dart` 提供共享构造函数，页面只传对象名与时间，不自拼句子。

| 类型 | 模板 | 例 |
| --- | --- | --- |
| 空 | 这段时间没有{对象} | 这段时间没有行程 |
| 首次空（从未有过） | 还没有{对象} | 还没有充电记录 |
| 加载 | 正在读取{对象} | 正在读取行程 |
| 刷新失败有旧数据 | 没能更新，显示的是 {DF7} 的数据 | 没能更新，显示的是 10:02 的数据 |
| 读取失败无数据 | 没能读取{对象} | 没能读取充电统计 |
| 分页失败 | 没能加载更多{对象}，已保留当前列表 | 没能加载更多行程，已保留当前列表 |
| 能力不支持 | 当前站点暂不支持{能力} | 当前站点暂不支持停放观察 |
| 版本不兼容 | 服务器返回的数据格式不受支持，请确认 Mileaf Server 版本 | — |
| 时区不可读 | 无法读取手机时区，暂按 UTC 显示和统计 | — |

技术原因（状态码、错误码、游标、字段名）只进「技术详情」，不进主界面。

## CP08 限定语

ADR0011 R09 冻结的意义全部保留，可以缩句，不能删义：估算、非实时、已记录费用及其覆盖、缺失、未知、口径不可比、样本少、相关非因果、非电池健康检测、停车有效时段与非预测、按结束日期统计。

- 每个指标旁至多一句（`footnote`），完整解释进「关于这些数据」。
- 常用句：「估算，按续航差计算」「未记录的费用不等于免费」「9 次中 8 次有费用」「按充入电池的电量计，仅含有费用的充电」「样本较少，仅供参考」「只反映相关性，不代表因果或优劣」「根据行程记录估算，不是电池健康检测」「只反映已记录的变化，不预测未来」「按结束日期统计，仅含已完成的充电」「额定续航，非实时」。
- 改名不能丢掉计算口径：口径信息若不在新名称里，必须作为同处限定语出现（例：「充入均价」旁注「按充入电池的电量计」）。

## CP09 禁止形式

1. 用「·」把多项拼成一行（含行内状态「充电中 · 11.0 kW」）；用逗号串三项及以上元信息。改为分行、分列、标签或一句完整的话。来自用户数据的字符串（如地点名「家 · 地库」）原样显示。
2. 单位当标签、标签里带单位。
3. 主界面出现服务端字段名、枚举原值、snake_case、算法版本、快照 ID、`schema`、`IANA`、`YYYY-MM-DD` 占位文字。
4. 用符号代替词：`↑ ↓` 代替增减、`#17` 代替记录、`pp` 代替百分点。
5. 同屏重复同一区间或同一单位。
6. 操作文字末尾带箭头字符、标签全大写或加字距。

## CP11 读屏与语义

- 读屏标签是完整句子，包含对象、数值、单位与限定：「本月驾驶 1,198.6 公里，比上月同期多 8.2%」。
- 图表语义提示：「拖动或轻点查看每天的值；可用调整手势切换日期」。删除可见的「点按读值」提示。
- 单位朗读用中文（公里、千瓦时、瓦时每公里、千瓦、百分之），由格式化器提供 `semanticsUnit`。
- 大内容查看器显示的是同一标签，不另写文案。

## CP12 冻结文案与变更控制

以下原文本轮只调整排版，不改一个字：HTTP 信任确认、地图隐私与底图授权、清除已保存 Key、退出此设备说明、费用补录后果（「仅补录本次充电。保存后无法在 App 中修改；单价不会设为默认值。」及计费说明）、连接替换说明。

对照表以外的改动由实施者按 CP01–CP11 执行，并在交接中列出每条「文件:行、原文、新文、规则」。凡是含义变化、涉及安全或写入后果、或对照表未覆盖而不确定的，先停下列给总控，由用户确认。
