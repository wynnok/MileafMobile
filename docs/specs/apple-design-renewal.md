## 3. 全局设计合同

尺寸为 Flutter 逻辑像素，字体为 TextScaler 之前的基值。颜色、字体、间距、圆角、材质与时长集中定义在设计层。页面只消费语义角色，几何常量归属对应共享组件。

### R11 布局与秩序

- 页面边距沿 `<390` 为 20、其余 24，内容最大宽 560，居中。模块间 24、章节间 32、标题到内容 12、读值与图 8、行内 4/8/12。容器内边 16。
- 一个连续区域采用一种分组方式。记录用行与细分隔，设置用共同背景的分组行，图表直接在内容底上绘制。圆角容器内部采用文字、图形和行。
- 标题、读值、坐标与记录文字按所在容器共用起始线。二级返回图标的可见边缘沿当前 `MileafNavigationRow` 与正文对齐。
- 控件最小命中 iOS 为 44×44，Android 为 48×48。布局以实际平台命中尺寸计算，视觉图标 20/24。透明命中区之间保持独立。
- 320/360/390/430/768 宽，100/130/150/200% 字号及非线性缩放均纳入矩阵。大字依据 `scale(14)>=21` 重排，原有完整金额、错误与授权后果保持可读。
- 标题、行、卡片自然增高。四项选择在窄宽或大字改 2×2，必要时单列。日期、说明与操作允许换行。横向滚动只属于已有业务图面或明确选择范围。

### R14 磨砂导航材质

使用白名单和固定预算，材质从独立共享组件消费。

| 区域 | 材质规则 |
| --- | --- |
| 根页浮动底栏 | 磨砂导航材质，内部只有一个选中底形 |
| 根页 / 二级顶栏 | 初始与 canvas 同底，正文实际经过时切磨砂导航材质，几何固定 |
| 全屏地图、内嵌地图的操作 | 实色 surfaceRaised，单独满足地图合成和文字对比 |
| 期间、指标轨道 | 普通实色轨道，选中底可平移 |
| 车况、记录、图表、设置分组 | 内容层 surface/canvas |
| 弹层正文、输入和提交区 | 实色 surfaceRaised，现有 scrim 分离上下文 |

材质 token 的初始确定值如下。F04 以这些值生成参考，任何调整均记入统一 token 差异表。

| 参数 | 浅色 | 深色 |
| --- | --- | --- |
| 背景模糊 sigmaX / sigmaY | 18 / 18 | 18 / 18 |
| 叠色 | surface，alpha 0.88 | surface，alpha 0.90 |
| 边缘 | text，alpha 0.10，1 物理像素 | text，alpha 0.14，1 物理像素 |
| 顶部内沿高光 | 白，alpha 0.35，1 物理像素 | 白，alpha 0.10，1 物理像素 |
| 外阴影 | text，alpha 0.10，Y=4，blur=16 | 黑，alpha 0.28，Y=4，blur=16 |
| 选中底 | 现有 segmentSelected，实色 | 现有 segmentSelected，实色 |

背景模糊按实际圆角 bounds 裁剪。高光固定、无扫光，光学参数保持静态。每一可见 route 至多两个有界 blur 区域，通常为顶栏和底栏。模态打开后，底层导航改同几何实色并暂停其反馈 ticker。地图页面全部导航实色。键盘打开时底栏隐藏，内容按 viewInsets 避让。

每个材质角色具有 `solid` 路径，使用 alpha=1 的对应 surface，并移除 blur、高光及阴影，保留几何和状态。透明度或高对比策略见 R18。按黑、白、主蓝、交错文字背景测试最终合成对比，背景越界样本使用 solid。性能对照退化触发交付手册的降级流程。[Flutter BackdropFilter](https://api.flutter.dev/flutter/widgets/BackdropFilter-class.html)

### R15 导航、控件与弹层

- 根页顶栏由 `workspace_page.dart` 统一构造，经既有 `topBar` 接缝注入，由页面负责固定布局、滚动边缘反馈和当前可见条件。统计 `topic=='overview'` 展示根顶栏，嵌入专题、长期索引和原始指标沿现有 `insightHeader` 的紧凑返回导航，顶部始终只有一组有效导航。概览显式下钻、Tab 保留专题和返回统计首页分别覆盖。F02 冻结该接缝，F04/F05/F06/F07 按各自持有文件接入。
- 根顶栏最小高 56，左侧 pageTitle，右侧车辆选择与设置。页面原有标题迁入该顶栏，期间和刷新继续由页面负责。车辆触发器按剩余宽度布局并提供完整名称弹层，150% 起标题与车辆操作分行。品牌保留于 App 标识、连接页与服务信息。刷新位于期间行右侧，各页每屏一个刷新入口。
- 四 Tab 目的地和顺序沿当前应用。底栏外侧距屏 16，下距安全区 8，最大宽 528，视觉最小高 64。图标 20、标签 12/16，内部上下 8、间隔 4，高度随文字增大并满足平台命中尺寸。选中底距外框 4，采用中性底形、强调色图标与标签。
- 使用真实测量的顶栏、浮栏和键盘占用计算有效视口。正文可以经过材质下方，停靠位置、焦点 reveal、末条记录及分页按钮须能滚动到完全无遮挡处，底部额外滚动余量为实际浮栏高度＋安全区＋8＋16。顶部 reveal 余量为实际顶栏高＋安全区＋8。
- 二级页保留当前紧凑左对齐返回导航，标题使用 navigationTitle，操作最多两个已有入口。其余现有操作收纳进已有说明或更多目的地时，能力表逐项登记。正常返回与系统返回沿既有 route 栈。
- 期间为紧凑轨道，日期为其旁独立动作。页面显示实际范围一次，选点读值另有精确时间。选中底是唯一移动底形。所有既有标签与 callback 保留。
- 主按钮最小高 48，输入最小高 52，沿 R11 平台命中尺寸。焦点即时出现 2px 环，线宽变化使用内描边避免内容移动。次操作用文字或已有次级样式。
- 设置分组内单行目标 56，双行 76，记录行目标 88，长字段自然增高。行内补录等局部操作拥有独立命中和语义。
- 底部弹层最大宽 520，顶部 28 圆角。标题与关闭独立行，内容单一滚动。普通弹层内容适高，长内容最大至顶部 SafeArea 下 12。费用表单沿原自管路由、关闭锁定与拖动规则，仅迁移呈现。

### R16 微动效与连续性

| ID | 触发 | 动画与参数 | 状态和打断合同 |
| --- | --- | --- | --- |
| M01 | 按下按钮 / 行 | 中性覆盖层即时出现，松手 100ms easeOut 消退，孤立按钮可缩至 0.98 | 命中区固定，取消恢复，列表行只改变覆盖层 |
| M02 | Tab 或互斥选中 | 单一选中底位移 180ms easeOutCubic | 选中语义和内容即时更新，连续点击从当前位置重定向 |
| M03 | 顶栏出现经过内容 | 叠色 120ms easeOut，不改变栏高和 blur sigma | 按实际内容位置，非每帧 setState 重建全页 |
| M04 | 进入详情 / 设置 / 证据 | 沿平台标准 route 转场，复用 Navigator 与返回手势 | iOS 交互返回、Android 系统返回由平台路由接管 |
| M05 | 打开 / 关闭弹层 | 位移与遮罩，进入 280ms、退出 220ms，easeOutCubic | 沿现有可关闭条件，连续打开只保留一个有效 route |
| M06 | 折叠说明 | 内容自然重排，箭头旋转 160ms easeOutCubic | 语义即时改变，焦点保持在触发项 |
| M07 | 图表拖动 / 步进 | 十字线、点、读值直接跟随，按数据点离散选择 | 拖动期间即时读值，保持既有选择与手势仲裁 |
| M08 | 刷新 / 数据替换 | 保留旧快照及状态文字，可用 120ms opacity 交接 | 数值即时正确，身份变化立即销毁旧快照 |

所有自定义动画在 reduceMotion 时为 0ms，route 选择无位移即时过渡，加载使用带状态文字的静态提示。动画运行期间设置变化立即收敛到正确终态。首帧内容完整，数字保持真实值，图表完整绘制，装饰循环数量为 0。M02 采用固定尺寸底形的 transform，目标尺寸因大字/重排变化时即时布局。M06 按内容自然高度重排，采用指示箭头解释状态。

普通 Tab 点击只改变目的地，同一 Tab 重选沿当前行为。图表点选、滚动和期间切换沿原有语义，图面横向选点与页面纵向滚动分别通过测试。触觉反馈仅在平台既有行为范围内沿用。VoiceOver/TalkBack 的连续读值避免逐帧重复播报。[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)

### R17 图表与数据表达

完整继承旧 R06。主图绘图区普通高 160，详情高 200，行程节奏高 88。字体放大时轴和图例占独立自然高度，图区保持可读。日期、单位、图例、读值各有唯一位置。

### R18 无障碍与材质降级

| 条件 | 必须表现 |
| --- | --- |
| 正常显示偏好 | R14 材质，R16 有限操作动效 |
| 减少动效 | 动效归零，玻璃按透明度偏好独立决定 |
| iOS 减少透明度 | 所有磨砂导航材质切 solid |
| 系统 highContrast | solid、明确选中形状与合格焦点 / 输入边界 |
| 偏好尚未知、桥接失败 | solid，恢复可用后按当前偏好更新 |
| 地图 route / 实际平台视图相交 | 该 route 导航和地图控件使用 solid |
| 材质对比失败、可复现性能退化 | 对应角色按 Q08 校准并登记 solid 决定 |

iOS 使用专用只读显示偏好桥接获取 `UIAccessibility.isReduceTransparencyEnabled`，监听变更通知，回前台重新读取。专用 channel 为 `mileaf/display_preferences`，方法 `getDisplayPreferences` 返回 `reduceTransparency` 布尔值，变更通过 `displayPreferencesChanged` 回调携带相同快照。每 App 实例一个监听，销毁解除。桥接不携带业务身份、地图配置或站点数据。

当前 Flutter SDK 的 MediaQuery 已有 disableAnimations 和 highContrast，iOS 减少透明度走上述接缝。Android 的 reduceTransparency 使用已知的 false 默认值，沿 MediaQuery 的 highContrast/disableAnimations 独立处理系统信号，平台分派在 Dart 偏好源内完成。R18 的桥接失败策略适用于 iOS 读取失败，Android 正常路径采用磨砂材质。各路径由注入偏好测试覆盖。App 透明度偏好沿系统读取，此版本保持无新增持久化字段。平台高对比实际映射需设备验证并记录，双端结果分别登记。

iOS 读取和通知使用官方 UIAccessibility 接口，启动读取异步执行，首帧先采用 solid，再按有效快照更新。[读取减少透明度](https://developer.apple.com/documentation/uikit/uiaccessibility/isreducetransparencyenabled)、[透明度偏好变更通知](https://developer.apple.com/documentation/uikit/uiaccessibility/reducetransparencystatusdidchangenotification)

所有现有交互覆盖默认、按压、焦点、禁用、处理中、错误、成功、指针 hover。无业务意义状态记 N/A。读屏顺序依视觉顺序，弹层关闭后恢复触发项焦点，图表有键盘和语义前后步进，错误有就近文本。授权信息、精确值和复制内容保持完整。[Apple Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

### R19 状态与恢复

每个数据区覆盖首次读取、空、失败、完整、已有数据刷新、局部失败与能力回退。骨架保持最终结构，状态文字提供可操作原因，局部失败使用原重试接缝。身份切换立刻清理旧身份视觉，普通刷新保留阅读位置与选点。输入错误保留原安全策略允许的字段。

费用结果待确认时以“查询最新结果”对应原流程。连接、登录、隐私和覆盖率信息在相关动作前后完整呈现。页面布局变化前后以语义锚点、已加载范围与当前 record ID 验证阅读连续性，原 offset 接缝沿当前实现复用。

### R20 工程与范围控制

共享设计文件单一所有者，页面使用同一组件系统。API、DTO、生成契约、session、workspace 与 reading_scope 默认只读。`workspace_page.dart` 允许调整壳层布局及测量接缝，`lib/main.dart` 允许注入显示偏好和路由主题，iOS 原生改动仅为 R18 显示偏好桥接。

保留既有回调、Key、路由、测试钩子、原生地图和数据算法。新增 HTTP 请求的预算为 0。所有主要内容首帧完整，隐藏页面 ticker 沿原隔离。原有测试定位如受真实重排影响，以等价实际点击与行为断言修正，并记录原因。

## 5. 首屏预算与质量门槛
