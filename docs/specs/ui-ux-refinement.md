## 1. 设计决定与完成定义

### 1.1 Hallmark Picks

- **Scope**：Flutter app screens，覆盖业务阅读、记录详情、统计专题、接入、设置、弹层和状态。
- **Keeps**：行笺品牌、电光蓝、Inter与平台中文字体、四Tab、单列移动布局、现有数据与导航能力。
- **Direction**：沿现有品牌定制“有秩序的数据阅读”；不抽新主题，不引入照片、插画或营销文案。
- **Hierarchy**：每屏一项主任务；数字用于概括，图表用于判断，记录用于查找，说明用于限定。
- **Signature**：紧凑车况、清楚的路线记录、可以读值与下钻的用车图表。产品记忆点由真实内容构成。
- **Surface**：中性底、细分隔、有限容器；概览一个深底状态锚点；无光晕、模糊背景、重复装饰卡片。
- **Motion**：只解释状态和反馈操作，不做数字滚动、绘图登场或瀑布式入场。
- **Material**：现有Flutter组件、合成HTTP夹具、已有地图能力；没有新后端指标、真实站点证明或设备性能结论。
- **文档关系**：审计提供问题依据，ADR0011记录全局取舍，本规格集中设计规则，Tickets管理执行依赖，交付手册规定验证与交接。

### 1.2 成功定义

以下全部满足才能称“本地代码与视觉完成”：规则R01–R10、行为S01–S08、页面P01–P16、验收G00–G08有对应证据；没有未解决阻断项；代表页按确认的参考渲染实现；全部原有业务能力仍可达；每个变化可解释为信息层级、可读性或操作效率提升。

## 2. 范围和不可破坏的行为

### 2.1 范围

包含所有当前用户可达页面和既有能力回退分支的呈现、组件、文案排版、手势反馈、可访问性与状态布局。不新增路由体系、依赖、图表库、字体包、埋点服务或后端接口。不迁移状态管理，不重构DTO，不调整业务计算。

不包含：车辆控制、多站点并行、多车比较、实时刷新、电池健康诊断、新预测/评分、真实数据迁移、生产写入、地图SDK替换、原生权限重构、发布与上架。外部仓库符号链接只读。

## 3. 全局设计规则

以下尺寸为Flutter逻辑像素，字号为TextScaler之前的基值。固定值只允许落入集中token或共享组件几何常量，页面引用语义角色；不得散落新的裸色值、字号、圆角、时长。R01–R10是规范，不是随意参考。

### R01 布局与对齐

- 页面左右：宽<390用20；≥390用24。主体最大宽560居中，表单弹层最大520。宽屏不新增第二列导航或桌面布局。
- SafeArea单独计算，内容底部不能被底栏遮盖；使用实际底栏高度+安全区+16的滚动余量，不继续假定固定84在大字下总是足够。
- 主内容、标题、轴标签、列表文字共享左对齐线。卡片外边采用页面边距，内边16；卡内文字相对于卡边而非强行和外部标题同线。取消12外距/16内距与页面20/24之间的无角色漂移。
- 栅格间距：4=紧邻图标/状态；8=标签到值/控件间；12=行内组/图表读值；16=容器内边/行上下；24=模块；32=独立章节。2只用于细微基线修正，需注释；不用临时18/28/40堆叠补白。
- 标题到所属内容12；说明到控件8；图表到读值8；读值到下钻动作8。父子不重复增加同一段间距。
- 布局使用约束与自然高度。表内高度为100%字号普通内容的目标/最小值，绝不是大字固定高度。

### R02 字体与数字

沿用Inter 400/500/600与现有中文回退；不引入第二展示字体。字体角色冻结如下，兼容旧字段名可做明确映射，不全仓机械替换。

| 角色（建议token） | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display` | 48/52 | 500 | 仅概览车况主值；每屏最多一个 |
| `metricLg` | 36/42 | 500 | 周期总计/专题主值；同一内容视口最多一个 |
| `metricMd` | 24/30 | 500 | 次级指标、记录主数 |
| `pageTitle` | 22/28 | 600 | 四Tab页标题；已有外壳不额外重复名称 |
| `title` | 18/26 | 600 | 二级页AppBar、模块标题、弹层标题 |
| `body` | 16/24 | 400 | 正文、记录标题、输入、重要操作 |
| `bodyStrong` | 16/24 | 500 | 行标题、主操作 |
| `label` | 13/18 | 500 | 字段标签、分组、筛选、图例 |
| `micro` / `detail` | 12/18 | 400 | 辅助时间/单位说明/图轴/错误说明 |
| `navLabel` | 12/16 | 500 | 底栏 |

普通文字tracking=0，数字display/metric允许-0.02em；所有数字用tabularFigures。中英文混排不能对整段人为加字距。数字和单位优先基线对齐、间距4；换行时数值完整，单位随后，不单独把单位推到无关联位置。

任何功能文字基值≥12；自绘图轴/电池弧/构成环中心都包括在内。不能用opacity降低文字到不达标，不能用FittedBox、局部TextScaler.noScaling或放大封顶来塞入既定高度。巨大缺失符号不充当主视觉：缺失主值用24号“—”+“暂无…”，同时保留相关口径。

数字格式沿用 `number_format.dart` / `currency.dart` 的业务精度与币种；视觉不能改写全局舍入。历史主值若需统一小数位，先做字段列表与舍入算例，作为明确差异；本轮默认不改精度。ID保留在说明层，日期列表用站点日期、详情同日用日期一次+起止时分，跨日和跨年完整标明，精确秒级时间仍可查。

### R03 自适应与大字

- 320、360、390/430、768宽均支持；基础字号100%、130%、150%、200%。以 `TextScaler.scale(14)>=21` 判断大字布局分支，跟随平台非线性缩放，不只读取线性倍数。
- 大字优先变布局：指标3列→2列→1列，记录主数移到下一行，四专题2×2→单列；标题与动作分行。不得减小全局字体换取首屏目标。
- 车辆长名称在顶栏允许尾部省略，但弹层提供完整名称与选中标识；金额、错误、授权后果、地图状态不得省略。地点列表100%最多两行，详情完整显示。
- 短标签互斥控件在可用宽下每段≥44；不足时改两行/纵向选项，不做挤压省略。四指标控制器320宽或150%以上采用2×2，200%必要时单列。
- 页面不产生横向溢出。图轴可减少tick，不能裁字；证据字段可折行，URL显示可折行，复制值必须完整。

### R04 色彩、表面与圆角

- 保留现有浅色canvas `#F4F5F7`、surface白；深色canvas `#0A0B0D`及surface档位。图形accent、文字accentStrong、深底accentHero继续分工。
- 正文和辅助文案≥4.5:1；大字、必要图形、焦点/输入边界≥3:1。按最终合成背景计算。阈值是本项目验收基线，不声称本轮已完成全部无障碍认证。
- 分隔线可低于3:1，但不能是唯一交互/状态辨识方式。现有lineStrong不得自动当作合格输入边界；若不足，新增语义 `controlBorder`，从现有足够对比的中性文字色派生，经过测试。
- 概览车况保留一个深底卡片，浅深模式同样外距、20圆角、无光晕。其他页默认同底，费用/统计/停放不使用深底Hero。深色以surface轻微区分，不用阴影堆叠。
- 列表无逐行底卡；需要共同背景的表单/状态/选中组可使用surface。禁止卡中卡、图标圆币、纯装饰圆点、渐变字、发光与BackdropFilter装饰。原有底栏改实色，非地图内容不得模糊。
- 圆角按角色：普通按钮/输入/互斥组12；地图容器/概览卡片/弹层顶部20；图中柱端2；仅开关滑块、选中点、原生握柄可用全圆。不可为了统一把同意弹层变成巨型胶囊。
- 颜色不表彰未判定好坏的涨跌；里程增加只表示变化，不自动用成功色。error/warning必须有文字，不以整页红底制造紧张。

### R05 控件、表单和导航

| 对象 | 视觉与交互合同 |
| --- | --- |
| 主按钮 | 默认最小高48，横内边16，16/24/500；同一区域一个主操作；loading保持标签并禁重复，不跳宽 |
| 次操作 | 文字或线框，最小高44；无串联箭头字符；危险操作独立行，保留确认 |
| 图标按钮 | 图标20或24，**实际**命中区≥44×44；Focus即时2px外环；tooltip+语义名称 |
| 期间/指标选择 | 一组共用中性轨道，12圆角；选中surface+文字/指示，不是每项蓝描边胶囊；每项最小44高；语义selected |
| 日期动作 | 位于期间同组末尾；单独按钮且有名称；选择后显示实际范围，原有默认期间不变 |
| 列表行 | 最小72，普通双行目标88，长地点允许增高；纵内边12；主数24、次信息12；整行可点但局部费用动作独立不串跳 |
| 输入 | 最小52，字16；字段标签13常驻，说明/错误12；不以placeholder代替标签；焦点边不改变内容尺寸 |
| 底栏 | 四项不变；默认64高，图标20、文字12、间隔4；大字按实际文字增高；选中蓝+既有位置标记，非纯颜色 |
| 顶栏 | 默认56最小高；品牌保留，车辆可切换，设置入口保留；200%采用两行且车辆有独立44命中区 |
| 弹层 | 顶20圆角，最大520；标题18、关闭44；可滚动内容，viewInsets+SafeArea；需要提交时仅一个主动作 |

所有控件逐项验证默认、按压、焦点、禁用、处理中、错误、成功，以及有指针设备的hover；无意义状态记N/A并说明（例如返回按钮不需要服务器成功态）。焦点不能淡入，关闭后返回触发控件，读屏顺序符合视觉顺序，非交互图形不能假装按钮。

表单业务校验时机保持既有契约；新共享样式不得改变费用预检/提交/关闭锁定。错误就近并保留输入（登录口令清理保持原安全策略）。成功只以真实响应为准；本来就能看到结果的操作不再加庆祝toast；复制操作保留既有确认反馈。

### R06 图表与数据阅读

1. **形态**：日里程/电量/费用/次数用柱或现有竖线；速度/功率/SOC/长期中位数用折线；条件分组用点图；停放变化用正负柱；AC/DC保留既有构成环和精确图例，不增其他环图。
2. **尺度**：柱从零起，负值保留负轴；SOC固定0–100；参照与本期同单位同轴；不同单位切换，不做双Y轴。长期续航局部缩放必须可见标注轴范围，不暗示电池健康。
3. **主图**：绘图区高160（不含标题/控制器/读值）；专题/详情200；列表紧凑节奏88。主图默认3个Y tick、X轴首中末至多3个；紧凑节奏可无Y轴，但读值必须有单位。
4. **轴布局**：自绘文字沿R02并应用完整TextScaler。左侧留白按最长tick TextPainter宽度+8计算，底部按实际行高+8计算；大字减少tick到2、扩大所需高度，不能固定34/18导致截断。端点留至少8给选中标记。
5. **几何**：主线2，参照1.5虚线4/4；普通柱宽上限12，端圆角2；选中点半径4、外环8；网格最多3条轻细线，只有数据/选中线需高对比。面积填充仅可作冗余辅助，不能唯一编码量级或缺失。
6. **读值**：图下固定语义结构“日期/时间 → 当前值+单位 → 可比时的参照与差值 → 下钻”；大字自然增高。选择不弹遮图tooltip，不随手指滚动数字动画。参照显示真实区间名；配对比较/不可比/样本不足不伪造百分比。
7. **操作**：复用点按、横向拖动、键盘左右、Semantics增减；纵向拖动应滚页面。不同数据身份变化沿既有选择重置逻辑，普通返回保留选点；不能新增默认选点策略导致既有阅读行为变化。显式上一/下一按钮保留，视觉可缩为图标44，语义仍为“前一个采样”等。
8. **缺失**：null断线、留槽并说明；真实0画在基线；无样本不画全零曲线。统计样本数/覆盖不足的限制在图旁可见，不全部藏入说明。
9. **日历**：≥390宽、<150%可保留七列，但按当前内容宽度验证每格≥44及4间距；不足时用四列“日期矩阵”，显示月/日，不冒充星期日历。150%以上改按日行列表，保持每日值/选择/下钻，不仅输出文字总计。零=明确0，未知=—，四档阈值继续0/<50/<100/≥100；用边界/填充纹理+图例区分，不能只依赖透明度。图案来自Painter，不新增素材。
10. **状态占比条**：在线实色、睡眠中性实色+斜线、离线中性实色+点纹、未知空底+描边；类别名/小时/百分比始终并列可查。具体中性色取现有palette并通过合成对比测试；纹理线1、间隔6。窄片段不强设最小宽以免伪造比例，靠图例辨识。

### R07 微动效

| 事件 | 时长/曲线 | 允许表现 | 禁止 |
| --- | --- | --- | --- |
| 按压 | 100ms easeOut | 中性覆盖层变化 | 整卡弹跳、缩放所有元素 |
| 互斥选中 | 160ms easeOutCubic | 选中底色淡入；控件尺寸固定 | 宽高过渡、闪白 |
| 局部快照更新 | 160ms easeOut | 内容准备完成后一次opacity过渡，数值即时正确 | 数字计数、旧/新值叠成两份语义 |
| 折叠指示箭头 | 160ms easeOutCubic | 旋转，内容默认即时重排 | 自写高度Tween、长时间占位 |
| 弹层 | 240ms easeOutCubic | 框架路由平移/淡入 | 弹簧/过冲、嵌套入场 |
| Tab返回/滚动恢复 | 0 | 直接保留既有画面 | 每次整页淡入、滚回顶部 |
| 图表首次/刷新 | 0（几何） | 完整真实图形立即出现 | 500ms画线/柱从0生长 |
| 初次加载 | 静态骨架 | 已知结构对应形状；语义“正在加载” | 无限shimmer或屏幕内容不可见 |

`disableAnimations=true`时全部装饰/位移动画归零，焦点与数据即时可见。原生导航转场遵循平台/Flutter设置，不在视觉任务重写路由。进度条减少动效时使用静态进度提示+文字，不能残留无限转动。禁用动效不禁用请求和反馈。无需新增触觉反馈。

### R08 状态与恢复

| 状态 | 必须显示 | 操作与布局 |
| --- | --- | --- |
| 首次加载且无快照 | 对应模块静态骨架、读取语义 | 不显示假值；模块独立，不整页阻塞 |
| 同查询刷新 | 保留完整旧内容、轻量“更新中” | 选点/滚动不变；不能白屏 |
| 新查询仍在请求 | 目标期间清楚；若显示旧快照，明确旧期间及更新中 | 不把旧数据标题改成新期间；沿既有身份策略 |
| 真空数据 | “这段时间没有…”、区间 | 可调整日期；收缩空图，不画假曲线 |
| 字段缺失 | —及缺失原因（若契约提供） | 其他已知指标照常显示 |
| 局部失败且有快照 | 旧数据时间+“更新失败” | 当前资源重试，不清空其他资源 |
| 局部失败无快照 | 简短原因+重试 | 页内状态区，最小自然高度，不占整屏 |
| 能力不支持 | “当前站点暂不支持…” | 保留可用旧能力，不能反复重试不支持接口 |
| 认证失效/换车 | 既有登录/切换流程 | 清除旧身份画面，不展示敏感旧快照 |
| 地图无Key/未同意/待重启/失败 | 对应准确状态、一个恢复动作 | 路线速写和说明分区，不在图上盖大卡 |

错误不要只显示技术异常；可展开原有诊断信息但不得泄漏token/Key。429、Retry-After、手动恢复边界和重试次数保持原行为。

### R09 文案与信息披露

- 页面名称使用现有中文领域词；分组标题直接命名内容，不额外添加装饰眉标。
- 元信息不用“·”拼成长句，改成分行、列或有语义的短句。起终点箭头可作为路线图形保留，不能粘在链接文案末尾作装饰。
- 刷新用图标按钮并保留具体tooltip，避免标题旁长串“刷新能耗条件”。“数据说明”在章节尾部，必要限制在指标旁。
- 冻结意义：估算、非实时、已知费用及覆盖、缺失、未知、口径不可比、小样本、相关非因果、非电池健康检测、停车有效窗口/非未来预测、按结束归期。可缩句但不能删义。
- 涉及HTTP信任、隐私授权、Key清除、退出设备、费用写入后果的原文默认不改；仅重排。若要改义，先列逐句前后和理由，不能交给页面Agent自行润色。
- 例：“行程 #17”→“行程详情”，ID进入数据说明；“四个问题”→“用车专题”；“前一个采样”视觉可用图标，tooltip/读屏名称保留；“参照”→从实际查询生成的“上期同区间”等准确名称，无法证明时展示日期范围。

### R10 工程约束

复用现有primitive→semantic→component结构。允许新增 `pageTitle/bodyStrong/navLabel/controlBorder` 等明确缺失角色，以及一个共享互斥选择组件；不得引入页面自建主题、通用布局DSL或万能状态容器。图表修改集中共享Painter，专题Painter沿同一文字/选择规则。

不删除路由、组件树或既有测试来通过验收；局部重排Widget子节点必须列保留的数据/动作清单。允许改与新规格明确冲突的像素/文案断言，但需映射到规则ID；业务断言不得放宽。生成DTO、依赖清单和锁文件默认零变化。

## 4. 逐页规格

页面顺序为从上到下。主视口目标仅用于360×800、100%、普通短内容的参考夹具；大字/长文本/错误提示以完整可达为先。所有页面需继承R08，不为每页单独设计不同错误样式。

### P01 概览

顺序：外壳 → 紧凑深底车况 → 周期选择 → 周期摘要 → 指标选择与每日主图 → 最近记录 → 继续探索 → 数据说明。

- 车况卡普通目标高180–208，状态与更新时间同组；续航48与电池弧并排；今日里程/趟数/估算消耗24一行，说明12。无车况时收缩，已知今日数据保留。
- 周期总里程36，差值与实际比较区间一组；其他已存在周期指标24/正文行，不能删V01四主数能力。低优先级明细留在图后“驾驶与补能”区域或已有说明入口，迁移表逐项列出。
- 图表控制器保留当前四项“里程/电耗/补能/费用”。`_Metric.energy`是已有代码分支，不据此新增第五个可见tab；驾驶消耗等现有说明/明细能力仍逐项保留。首屏能看到实际绘图区至少80高。
- 最近行程/充电各一个，继续探索沿现有目的地；不添加智能推荐/预测。

### P02 行程

顺序：外壳 → 标题/日期 → 期间选择 → 紧凑汇总 → 88高节奏图与行内读值/看当天 → 按日期记录 → 数据说明。

- 汇总距离36，趟数/估算能量/净电耗13–16分组，不再60号距离+长串说明。
- 记录起终点作为主文，距离24右侧；时间/时长/净电耗辅助；取消路线图标圆圈。普通记录最小88，两行地点增高，不挤压数字。
- 默认第一条完整记录与下一条开头在首屏；“看当天”保留原过滤语义，返回后选点、分页和滚动保持。
- 不把节奏移进默认折叠，图形是本页必要内容；压缩的是包装与重复文案。

### P03 充电

顺序：外壳 → 标题/全部记录/期间 → 正在充电（有才显示） → 紧凑账目摘要 → 每日补能图 → 最近充电 → 我的补能方式 → 地点账目 → 数据说明。

- 摘要同底：已知费用36，覆盖和均价13，电量/次数/时长24；覆盖只完整写一次，保留对应已知入电量。
- 每日补能紧凑88高，保留电量/费用/均价/次数切换；首屏显示第一条记录起始至少44高，无正在充电时第一条完整可见。
- 记录保留0–100% SOC区间图及起止数值、能量、费用、时长、类型；零元、缺失费用、进行中不同呈现。
- 全部记录和地点下钻目的地不变；“补录费用”独立44动作，点击不能触发行导航。
- 构成环保留、挪到记录之后，AC/DC/未知与绝对值/分母说明仍完整可达；大字图与图例上下排。

### P04 行程详情与地图

顺序：AppBar“行程详情” → 路线与日期简短摘要 → 地图 → 距离/时长/净电耗 → 过程图 → 其余指标 → 数据说明。

- 摘要不重复距离时长；记录ID、精确时间、路线非导航限定有明确位置。地图正常内嵌高220；“查看完整地图”沿现有展开入口。
- 未配置/未同意/失败用高120的真实路线速写（有可用点时）+下方自然高度状态行。无轨迹仅说明，不画假路线。地图失败不阻断速度/SOC/海拔。
- 真底图和速写都可展开，关闭回原阅读位置；加载时不能抖动反复切高度，当前地图状态确定前按最近已知状态占位。
- 高度改变仅是呈现规则，不改MapPanel授权/Key/原生生命周期；完整隐私说明由既有同意弹层承载，入口不代表同意。
- 首屏正常态显示完整地图、三项主指标和过程图区起始至少64；降级态过程图应更早出现。

### P05 充电详情

顺序：AppBar“充电详情” → 地点/日期 → 紧凑SOC摘要 → 电量/费用/时长 → 功率或电量过程图 → 地图 → 其他指标/数据说明。

- SOC弧保留88，但不居中占据大块Hero：与“18% → 82%”及结束/进行中信息并排；普通SOC摘要目标≤112；无数据不补起终点。
- 三项结果分列、数值24，标签13；费用补录入口就近，0元不显示补录。
- 默认功率，保留切电量、完整曲线目的地、样本前后操作和限制；首屏图绘图区≥120。
- 旧/新详情契约分支均可达；不可强制依赖expandedDetail才显示新样式。

### P06 统计首页与全部指标

顺序：外壳 → 标题/全部指标 → 期间 → 一项主结论与限定 → 同底里程主图 → 用车专题2×2 → 更多与数据说明。

- 主结论36，比较只在可比时显示；辅助净电耗/已知费用/活跃日13–16，不重复在主图后再做同值强调行。
- 主图160、无深底卡；“依据”放在结论/比较旁的44动作，保留原证据目的地。
- 专题固定“节奏→usage、能耗→energy、补能→charging、长期→long”。`long`继续进入已有“长期”索引，其中保留`range`长期续航和`parking`停放观察两个入口；不能把长期格直接改跳续航而丢掉停放，也不新增重复直达行。
- 每格仅标题、一个结果/状态、一个简短限定，无嵌套卡。100%首屏完整显示专题第一行；200%改单列。
- 全部指标为完整指标索引，保留所有字段和旧版能力入口，不作为丢失能力的垃圾箱。

### P07 用车节奏

顺序：AppBar → 所选期间 → 活跃天数36与总里程/每日均值 → 每日用车图 → 证据指标 → 距离分组 → 星期节奏 → 数据说明。

使用R06日历/日期矩阵/大字逐日布局；保留0、未来日期不补0、按日证据下钻。点击日期后查看该日记录，日期源沿站点时区，不新增客户端均值。四档图例必须可理解，禁止纯透明度区别。

### P08 能耗条件

顺序：AppBar/期间 → 所选组净电耗36与样本限定 → 温度分组点图 → 分组选择/前后操作 → 覆盖与证据 → 距离分组 → 数据说明。

组标签显示“−5至0°C”等易读短名，并在图例或说明明确左闭右开；读屏保留精确区间。只显示真实分组值，不插值；小样本、相关非因果在主值旁，不能改成“最佳温度”。刷新用图标。大字下分组选择不产生三行胶囊残片。

### P09 补能统计

顺序：AppBar/期间 → 已知费用36+覆盖/均价 → 互斥指标/主图 → 查看期间记录 → 证据 → 补能结构 → 地点账目 → 数据说明。

与P03同一口径但强调分析。入电量、已知支出、有效入电均价、次数四选项采用2×2或单列自适应；短显示词可为“电量/费用/均价/次数”，图标题和读屏仍说完整口径。零与缺失保持；进行中不加入已结束统计。

### P10 长期续航

顺序：AppBar → 独立6/12月选择与说明 → 所选月中位数36 → 趋势与P10–P90带 → 月读值/前后操作 → 证据 → 数据说明。

“记录估计，非电池健康检测”紧邻主值；波动带有图例，不补缺月；当前未结束月明确。月窗口不继承主Tab短周期；折线坐标若非零起点显示范围说明，避免夸大变化。

### P11 停放观察

顺序：AppBar/期间 → 有效窗口SOC变化36/样本量 → 正负图 → 读值/前后操作 → 状态时间分布 → 证据 → 数据说明。

无深色Hero；主值单位“百分点”，图轴可用pp且就近定义。正值回升、负值下降都不是系统判定好坏；标准化率不是未来预测。分布严格使用有效窗口观测小时为分母，采用R06纹理方案；局部缺失不伪造全日状态。

### P12 设置、地图设置、外观、币种、服务信息

保持已有层级和导航。设置“使用偏好/当前站点”分组13，行标题16，次说明12；去图标圆圈，行内图标20，行最小72。少量设置不强行填满屏幕。

地图设置保留“本机配置/申请帮助/地图隐私”三段、两个默认折叠、已保存/编辑、危险清除、设备绑定信息与复制、隐私授权与待重启。跟随新字号后不得再使用旧规格“global tokens零改动”阻止已批准的全局增量；授权、controller与冻结tooltip仍不得改变。

外观顺序跟随系统/浅色/深色；币种未知不默认为CNY；选择反馈真实持久化结果；服务信息可复制完整值但不展示密钥。地图Key展示继续掩码；教程已有用户修改需保留并做差异合并，不能覆盖。

### P13 连接、登录、初始化与连接管理

保留服务地址、HTTPS推荐、HTTP信任确认、站点口令与初始化路径。每页一个主要任务：检查连接、登录、初始化、验证并替换连接。标题只说一次，品牌只出现一次。

输入常驻标签与格式示例，错误就近；长URL折行但不丢反代路径与端口。连接验证失败保留现有连接；退出设备、HTTP信任与初始化不可因美化减少确认/风险说明。键盘操作顺序、提交状态、密码清理规则沿既有逻辑。

### P14 费用补录

顺序：弹层标题 → 记录地点/日期摘要 → 单价字段和币种 → 计费电量与预估说明 → 状态/错误 → 提交。

普通宽度可采用底部独立操作区，但320宽200%或可用高度<400时进入单一滚动流，避免固定摘要和按钮夹住输入。不能让操作区覆盖内容。金额不缩字、不截断；确认写入结果前不能显示成功。输入、关闭与重试状态严格服从S06/S07。
