版本 1.0，日期 2026-11-16，状态为 **accepted**。用户于 2026-11-16 确认 PD01–PD11 全部按提议采纳，实施按 [Tickets](apple-polish-tickets.md) 与[交付手册](apple-polish-delivery.md)分会话进行。各条修订在对应票实施并验收后生效；尚未实施的页面仍按 [ADR0011](../adr/0011-ui-ux-refinement.md)、[ADR0012](../adr/0012-apple-design-renewal.md)、[ADR0013](../adr/0013-liquid-glass-navigation.md) 的现状运行。

阅读顺序：[ADR0014](../adr/0014-apple-polish.md) → 本规格（规则 R21–R32、动效 M01–M12、页面增量 P01–P16）→ [文案与术语规范](apple-polish-copy.md)（CP01–CP12）→ [实施 Tickets](apple-polish-tickets.md)（AP00–AP15）→ [交付手册](apple-polish-delivery.md)（AQ00–AQ10、分会话方案）。

## 1. 方向与范围

### 1.1 现状判断

| 维度 | 判断 |
| --- | --- |
| 用途 | 车主在手机上读 TeslaMate：此刻车况、这段时间开了多少、花了多少、趋势如何、单条记录发生了什么 |
| 做对了、保留 | 四个目的地与 IndexedStack 阅读保持；液态玻璃悬浮底栏；同调车况卡；电光蓝只做信号；真实零、缺失、未知、估算的诚实表达；大字重排；可控 HTTP 测试和正式渲染体系 |
| 不精致的地方 | 一屏里同级的大数字太多，没有唯一重心；日期至少 7 种写法；元信息用「·」和逗号串成长句；单位被当成标签（「今日 km」）；分段控件白底加蓝下划线双重选中；各页读值格式、标题与控件的上下顺序各不相同；数据说明散落在正文中段；主界面直接出现「口径、基期、配对、快照、游标」和服务端枚举 |
| 坏掉的地方 | 数值放不下时单位被单独折到下一行（「46.8 / kWh」）；二级页两个刷新按钮使用两套图标、其中一个像「趋势」；三套日期输入方式；统计四格边线错位；按压是 Material 涟漪；停放与能耗专题显示 `partial_state_coverage`、`missing_soc` 等原始代码 |

### 1.2 Picks

| 项 | 选择 |
| --- | --- |
| 深度 | full（app 屏幕在原壳内重组）：四个目的地、路由、回调、Key、数据与阅读接缝全部保留；每屏重排重心、分组、层级与文案 |
| 视觉 | 中性底 + 模块卡；电光蓝只用于操作、当前选择、主数据系列、状态图形与焦点；容器圆角、控件胶囊、图标按钮圆形 |
| 重心 | 每个视口一处焦点数值；每个模块按「主值 → 一句话 → 证据」组织 |
| 材质 | 玻璃只在导航与控件层：液态玻璃底栏（ADR0013）、收起后的磨砂顶栏、顶栏镜片控件；内容层、弹层与菜单全部不透明 |
| 动效 | 手势触发、可打断、可减弱：选中镜片、按压、标题收起、读数切换、折叠展开 |
| 文案 | 平实中文、一个概念一个词、统一日期与数字格式；限定语就近一句，完整说明收进「关于这些数据」 |
| 签名 | 车况卡 + 读数头在上的期间图表卡 |
| 素材 | 现有 Flutter 组件、固定 HTTP 夹具与正式渲染；不新增指标、接口、图表库或字体包 |

参考依据：Liquid Glass 用于浮在内容之上的导航层，内容层保持清晰；iOS 27 对 Liquid Glass 的调整以可读性为先（更强的漫射、边缘更清楚），并继续遵循减少透明度与增强对比；系统栏项在大字号下不随字号无限放大，而以 Large Content Viewer 提供放大查看。来源见 ADR0014「参考资料」，各来源说法不一致的部分（例如默认透明度）不作为依据。所有尺寸、色值、时长均为本项目决定，不声称与系统控件逐像素一致。

### 1.3 范围

- **包含**：全部用户可达页面与状态（P01–P16）、共享设计层、文案、手势反馈、动效、无障碍表现。
- **不含**：业务逻辑、API/DTO、生成契约、读取生命周期、数值精度（除非用户另行确认）、新功能、新路由、新目的地、原生 Liquid Glass 平台视图、App 图标、后端、地图 SDK、依赖升级、底栏随滚动缩小（iOS 26 的 minimize-on-scroll，本轮明确不做）。

## 3. 全局规则

尺寸为 Flutter 逻辑像素，字号为 TextScaler 之前的基值。颜色、字体、间距、圆角、描边、时长只在设计层定义，页面只消费语义角色与共享组件。

### R21 重心与数值阶梯

1. 每个视口最多一个 `display`、最多一个 `metricLg`；其余数值用 `metricMd`、`metricSm` 或随正文。
2. 每个模块只有一个主值。顺序固定为「主值 → 一句话上下文（比较或限定）→ 证据（图、表或列表）」。
3. 读数头数值：根页用 `metricMd`；详情页与专题页用 `metricSm`。读数头永远比所在页面的焦点值小。
4. 同一信息每个模块只出现一次：区间、单位、期间名不在标题、控件和读数里重复。期间控件已经写着「本月」，模块标签只写「本月驾驶」一次，不再出现「10 月 · 2026」。
5. 三列网格（含详情页关键值行）只用 `metricSm`；两列网格可用 `metricMd`。数值与单位放不下时网格先改两列、再改一列，任何情况下单位不单独成行。
6. 焦点值周围至少留 12 的空白，同一行不放第二个同级数字；比较结果写成句子，不用箭头符号代替。
7. 自动检查：AP04 提供层级探针，统计有效视口内 `display` 与 `metricLg` 文字的数量；代表页与页面包的测试断言每个首屏机位各不超过 1。

### R22 字体角色

- 行标题字重：记录类行（行程、充电、地点）用 `headline`；导航类与设置类行用 `body` 400，Apple 设置页同样不加粗。

### R23 文字层级与色彩职责

1. 功能文字只有两级：`text` 与 `textSecondary`（新增语义名，值即现有 `textMuted`，浅 `#5A6672`、深 `#9AA5B1`）。`textFaint` 只用于占位符、禁用态和非文字装饰。缺失值「—」属于功能文字，用 `textSecondary`。
2. 电光蓝只用于四类：可操作（主按钮填充、可点文字、开关开启态）；当前选择（选中目的地、选择列表勾选、图表与日历的选中标记）；主数据系列；状态与入口图形（充电中图形、专题入口图标）与焦点环。标题、普通数字、增减方向、装饰不用电光蓝。
3. `warning` 与 `error` 只与文字同时出现。错误状态的标题用 `text`，只有图形与表单校验文字用 `error`；不出现整段红字标题。
4. 选中行不再填充 `accentSoft`，只显示尾部勾选。
5. `controlBorder` 从 `textMuted` 改为更轻的独立中性色，候选浅 `#808A95`（对 canvas 3.22:1、对 surface 3.51:1）、深 `#626C78`（对 canvas 3.69:1、对 surface 3.40:1、对 surfaceRaised 3.14:1）；AP01 以合成实测确认，任何相邻底色低于 3:1 即否决。
6. 对比门槛沿用：功能文字 ≥4.5:1，大字与必要图形 ≥3:1，焦点环与输入边界 ≥3:1，按最终合成背景计算。分段轨道上的未选文字按轨道底色计算（浅色 `textMuted` 在 `#E6E9ED` 上 4.82:1）。

**形状语言**：内容容器用圆角矩形，控件用胶囊，图标按钮用圆形。

| 弹层 | 顶部圆角（贴边）或四角圆角（浮动） | 28 |

**容器规则**

- 根页内容分为画布层（大标题、期间控件、区块标题、页尾脚注）与卡片层（模块卡、分组卡）。图表、网格和列表画在卡片表面上。

- 卡片网格（统计专题）同一行等高，格与格之间只有 12 的间距，不画竖线和横线。

**两条起始线**：画布层文字（大标题、区块标题、页尾）对齐页面边距；卡内文字、分组标题与分组脚注对齐卡片内边距（页面边距 + 16）。

### R25 页面骨架

**根页**（概览、行程、充电、统计）

1. 顶部外壳（R26）：展开态为大标题 + 车辆胶囊 + 设置圆钮。
2. 期间行（R27）：期间分段 + 行尾刷新圆钮，四个根页位置一致。
3. 焦点模块卡：主值、一句话上下文、图表与读数头。
4. 支撑模块：网格卡、记录分组卡、专题卡片。
5. 页尾：分组标题「关于这些数据」+ 默认折叠的说明分组（R30），最后是底栏避让余量。

**二级页**（行程详情、充电详情、设置子页、证据列表）

1. 紧凑返回导航（沿现有左对齐），标题 `headline`，尾部最多一个可见操作。
2. 身份块（画布层）：记录标题 `title2` + 一行 `subheadline` 元信息（日期与起止时间）。
3. 焦点模块：地图、电量卡或主曲线。
4. 关键值行，然后是支撑模块卡。
5. 页尾「关于这些数据」。

**专题页**（节奏、能耗、补能、长期续航、停放）

紧凑导航（专题名 + 刷新）→ 身份块（问题式标题 + 区间与统计口径一句）→ 结论卡（主值 `metricLg` + 上下文 + 必要限定）→ 主图卡 → 样本明细卡 → 关于这些数据。原「区间标题兼作数据说明折叠」拆开：区间进身份块，说明进页尾。

**弹层**：标题行（`headline` 左对齐 + 关闭圆钮）→ 单一滚动内容 → 需要提交时底部一个主按钮。

### R28 弹层与菜单

- 费用补录沿原自管路由、关闭锁定、预检与提交状态机，只迁移呈现。

### R29 图表语法

**模块内顺序固定**：（分段）→ 读数头 → 绘图区 → X 轴 → 图例（仅参照或多系列时）→ 限定脚注（可选）→ 下钻行（选中某天时）。

**完整读数头**（PD03，替代「读值在图下」）

| 行 | 内容 | 样式 |
| --- | --- | --- |
| 1 | 选中点的日期或时间（CP04），尾部为步进圆钮 | `subheadline` `textSecondary` |
| 2 | 选中值 + 单位 | 根页 `metricMd`；详情与专题 `metricSm`（R21.3） |
| 3 | 参照与差值或限定，写成一句：「上月同期 55.4 km，多 4.6 km」 | `footnote`（2026-11-18 用户裁定：比日期行小一号，手机卡宽内单行读感，不再折成两行） |

**紧凑读数行**：88 高的节奏图与每日充电图使用。一行内依次为日期、数值（`body` 600）、行尾下钻文字按钮；大字时自然折行；朗读来源与步进语义同完整读数头。

- 读数头在绘图区之上，手指拖动时不会被手指遮住。四段顺序沿 2026-11-16 概览读数区（日期 → 主值 → 参照 → 差值），参照与差值合并为一句。
- 默认选点不变：各页面传入的现有默认值（如概览默认最后一天、`SampleChart` 默认首个数据点）保持，读数头始终显示当前选中点。
- 读数头最小高度取各状态在当前字号下的最大值，切换时不跳高度。`readout` 句子仍是唯一朗读来源（live region），下钻行在 live region 之外。
- 「点按读值」「点按图形读值」之类提示删除，改为图表语义提示（CP11）。

**坐标与标记**

| 项 | 规则 |
| --- | --- |
| Y 轴 | 刻度文字在绘图区右侧，`caption` `textSecondary`，默认 3 个刻度；绘图区左缘与卡内文字起始线对齐 |
| X 轴 | 首、中、末至多 3 个刻度，格式按 CP04 DF9 |
| 网格 | 至多 3 条一物理像素 `line`，不画竖网格 |
| 柱 | 宽 ≤12，仅数值端圆角 `min(4, 宽/2)`；真实 0 是基线上的点；null 留空 |
| 参照 | 条形图上每个时间槽画一段短横刻度（宽 = 柱宽 + 4，1.5 线宽，`reference`），不再用折线把相邻日连起来；折线图上参照仍是 1.5 虚线 4/4 |
| 选中 | 1 逻辑像素竖线（`textSecondary`）+ 半径 4 的 `accent` 点和 2 像素卡片底色描边；取消光晕 |
| 图例 | 位于 X 轴之下，只列参照或多系列，参照名写真实区间名（「上月同期 9月1日–26日」） |
| 无数据 | 卡内一句「这段时间没有行程」，绘图区收起，不画全零图 |

键盘左右、语义增减、横向拖动选点、纵向滚动仲裁、普通返回保留选点、身份变化重置选点全部沿既有实现。

### R30 信息披露

1. 正文里每个指标最多一句限定（`footnote`，至多两行），例如「估算，按续航差计算」「9 次中 8 次有费用」。
2. 每个页面、详情和专题的末尾有统一的「关于这些数据」（PD08）：分组标题 + 一张分组卡，卡内为默认折叠的说明行。说明行固定分为五类，缺哪类就不出现：「口径与估算」「记录与缺失」「时间与时区」「来源与生成时间」「技术详情」。
3. AP00 把现有 25 处 `ExpansionTile` 分两类登记：**说明类**（数据说明、口径、校验时间、技术值，例如「速度数据说明」「采样数据说明」「曲线数据说明」「过程数据说明」「数据说明与更多」）迁入「关于这些数据」，内容不删、标题按 CP02 改名；**内容类**（停放记录逐行明细、电池加热重叠事件、地图设置的申请帮助与隐私说明等）保留原位。两类都改用 `MileafDisclosure`，不再直接使用 `ExpansionTile`。
4. 服务端字段名、枚举原值、快照 ID、算法版本只出现在「技术详情」内，可复制；主界面一律显示人话标签（CP10）。

## 6. 首屏预算

测量沿 ADR0012 §5：有效视口 = 全屏扣除系统安全区与实际遮挡的导航矩形；基准 360×800、safeArea 上下各 24、100% 字号，另补 safeArea=0。根页按展开态外壳测量。

| 页面 | 目标 |
| --- | --- |
| 概览 | 车况卡完整、期间卡主值与读数头完整、绘图区至少首 80 可见 |
| 行程 | 第一条记录完整、第二条起始至少 24 可见 |
| 充电 | 无进行中时第一条记录完整；有进行中时记录标题与首行至少 44 可见 |
| 统计 | 用车专题第一行两张卡片完整可见 |
| 行程详情 | 正常地图、三项关键值、过程图读数头与绘图区首 64 可见 |
| 充电详情 | 功率绘图区至少 120 可见 |
| 五专题 | 结论卡与主图绘图区首 120 可见 |

**退让阶梯**（AP07 按顺序执行，前四步在本规格范围内可自行完成，不必停下）：

1. 删除重复信息（区间、单位、期间名）与无内容的包装。
2. 焦点卡上下内边距由 16 收紧到 12。
3. 根页焦点卡改用紧凑读数行（R29）。
4. 把焦点卡内的次级三格移到图之后。
5. 仍不满足时，准备两个候选（例如主图绘图区 160 → 140，或调整模块顺序），连同实测、截图与影响放入视觉评审包。
6. 由用户在评审中裁定预算或候选，裁定结果写入冻结清单。

页面包不得自行放宽预算；AU25 的两处现有失败由 AP00 先归因，再按本阶梯处理。
