# 自备高德地图 Key 设计规格

- 日期 2026-11-09
- 依据 [ADR 0008](../adr/0008-user-amap-key.md)，用户确认 ADR 后授权继续完成实施。
- 范围为双端原生底图、本机配置与设置交互。

## 1. 入口与阅读顺序

「概览 → 设置 → 服务版本与兼容性 → 地图」沿用当前服务信息路由。服务信息页标题为「设置与服务」，原「地图与隐私」行改为「地图」。地图不可用时，在详情地图的路线速写提示中直接提供「配置地图」入口。两者进入同一个 `MapPrivacyPage`。

页面顺序为 AppBar、配置状态、作用范围、当前平台 Key、保存或更换动作、申请帮助折叠区、地图隐私。主操作靠近输入框，整体随键盘调整高度并可滚动。现有页面内容与数据区布局由原组件继续承载。[入口实现](../../lib/src/overview_page.dart)、[配置页](../../lib/src/map/map_privacy_page.dart)

## 2. 色板、字体与几何

| 项目 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#F4F5F7` | `#0A0B0D` | 页面底 |
| surface | `#FFFFFF` | `#12161C` | 输入面 |
| text | `#0E1319` | `#F2F4F7` | 正文、标题 |
| textMuted | `#5A6672` | `#9AA5B1` | 次级说明 |
| accent | `#2688F5` | `#64A8FF` | 状态图标 |
| accentStrong | `#0B62C4` | `#64A8FF` | 链接、主按钮 |
| warning | `#B45309` | `#FFB020` | 待重启提示 |
| error | `#CE271B` | `#FF7A70` | 错误与校验 |

颜色只通过 `MileafColors` 消费。字体沿用 Inter 与系统中文回退。页面标题为 18/22、600，输入、操作与关键说明为 13/19.5，分组短标签沿用现有 label。错误文案继承主题 detail 12/17，允许四行。状态通过文字和语义共同传达。[token](../../lib/src/design/tokens.dart)、[字体](../../lib/src/design/typography.dart)

- 页面由 `MileafContent` 居中，最大宽 560。宽度小于 390 时左右 20，390 起左右 24。
- AppBar 后内容顶距 12。图标与状态文字间隔 12，状态与说明间隔 12，表单前距 20，分组间隔 28。
- 字段标签后距 8，输入后距 12，保存反馈前距 8。
- 输入框 12 圆角、16×12 内边距。默认边线 1，聚焦 2，使用现有 focusRing。
- 按钮 10 圆角，至少 44 高。显示切换、复制、清除等操作触达至少 44×44。
- 图标沿用 24 网格、1.5 线宽。状态使用 `mapPin`，隐私分组使用 `info`。
- 页面以面与分隔线建立层级，弹窗继承现有 dialogTheme。动效沿用路由与主题，遵循减少动态效果。
- 320/360/390 均为单列，150% 起遵循既有大字号规则。200% 字号允许输入与操作自然增高，技术标识允许换行。

## 3. 表单与状态

| 状态 | 用户可见反馈 | 行为与验收 |
| --- | --- | --- |
| 读取中 | 正在读取地图配置 | 停用编辑 |
| 读取失败 | 地图配置读取失败、重试读取配置 | 保持速写，成功重读后恢复操作 |
| 无配置 | 未配置 · 使用路线速写 | 展示当前平台输入框与保存动作 |
| 编辑 | Android 地图 Key 或 iOS 地图 Key | 默认遮挡，用户主动显示或粘贴，关闭纠错与建议 |
| 校验失败 | 输入附近具体错误 | 去掉首尾空白，要求 32 位 ASCII 字母数字，空白与中间空格拒绝写入 |
| 保存中 | 正在保存… | 停用重复提交、编辑、清除及返回 |
| 已保存 | 已保存、脱敏末四位 | 通过「更换 Key」显式编辑，取消更换丢弃草稿 |
| 待重启 | 已保存 · 重新启动后生效 | 正文说明结束进程后重新打开，本次运行仍使用原 Key |
| 保存失败 | Key 保存失败，请重试；原配置仍保留 | 保留草稿与已有配置 |
| 清除确认 | 清除地图 Key？ | 确认后写入清除结果，成功则立即阻止新地图并卸载当前地图视图 |
| 清除失败 | 清除失败，请重试；原配置仍保留 | 配置保持有效，可重试 |

保存反馈仅表达本机存储结果。地图加载结果由地图组件表达。首次保存且 SDK 尚未初始化时，已保存 Key 可供下一次地图创建使用。已有 SDK 初始化后冻结进程 Key，更换后仍使用旧值，改回原值可取消待重启。清除后重新填写的值也受同一进程快照约束。

`MapKeyController` 先持久化再发布新值，busy 排斥并发写入，失败释放 busy 且保留原值。本设备登录退出、站点与车辆切换保留配置。冷启动恢复配置完成后运行 App，恢复失败提供重试。[配置模块](../../lib/src/map/map_key.dart)、[启动入口](../../lib/main.dart)

## 4. 双端配置桥接

应用级 `MethodChannel('mileaf/map_configuration')` 提供 `getBinding`，返回 `Map<String,String>`。Android 返回当前包名与当前安装包签名证书 SHA-1，多签名时分项展示。iOS 返回当前 Bundle ID。读取失败返回 `binding_unavailable`，UI 支持重试。读取绑定信息使用系统接口，独立于高德 SDK 初始化。

同一通道提供 `getProcessKey`，返回 `String?`。非空值是当前原生进程锁定的 Key，空值表示本进程尚未设置 SDK Key。冷启动和同进程 FlutterEngine 重建都在配置恢复阶段读取该值，恢复进程快照与待重启状态。该值仅在本机内存流转。

高德平台视图创建参数增加 `apiKey`，与 `consent`、`scene`、`interactive` 并列。场景编码 `AmapSceneWire` 保持原契约。两端原生再次检查同意和非空 Key，并锁定进程第一个 Key。Android 在 `TextureMapView` 创建前调用 `MapsInitializer.setApiKey`；iOS 在 `MAMapView` 创建前设置 `AMapServices.apiKey`。配置缺失阻止原生地图创建。

移除 Android Manifest 构建期 Key、iOS plist Key 与 xcconfig Key include。用户本地私有文件保留原状。Key 以独立安全存储记录保存，示例、日志及渲染夹具使用合成值。[Android 入口](../../android/app/src/main/kotlin/app/mileaf/mileaf/MainActivity.kt)、[Android 地图](../../android/app/src/main/kotlin/app/mileaf/mileaf/map/AmapPlatformView.kt)、[iOS 入口与地图](../../ios/Runner/AppDelegate.swift)

## 5. 地图与隐私

状态优先级为无坐标、配置缺失或读取失败、隐私未同意、平台不支持、加载与结果。缺配置直接显示路线速写与配置入口，避免等待 15 秒。加载失败显示速写、重试及地图设置入口。每次状态转换都重新检查配置和同意，清除后旧视图回调不得复活地图。

填写 Key 与隐私同意独立。地图页下方保留当前授权状态、关闭或重新启用按钮、供应商说明和可复制隐私链接。已初始化 SDK 关闭后可能保留进程内存，页面说明重启边界。[MapPanel](../../lib/src/map/map_panel.dart)、[MapConsentController](../../lib/src/map/map_consent.dart)

## 6. 申请帮助与教程

「如何申请 Key」默认折叠，首次展开读取绑定信息。内容按创建应用、选择当前平台 SDK、填写当前包绑定信息、复制 Key 并保存四步组织。绑定值使用可选择正文，每项有独立复制操作与成功反馈，失败可重试。固定步骤与安装包实时身份分离。

申请教程与设置教程交付到 `docs/tutorial/`。覆盖 Android 与 iOS、不同安装包签名、首次保存、更换、清除、重启、隐私与加载错误。高德控制台的额度与资格信息以用户账户当前页面为准。

## 7. 验证矩阵

- 配置边界覆盖首次保存、初始化后更换、改回、清除、存储失败、非法输入与冷启动恢复。
- 页面边界覆盖速写进入设置、保存返回、清除恢复速写、绑定信息延迟读取与复制、窄屏双倍字号。
- Flutter 正式组件渲染覆盖浅深各六种状态，使用 360×800，以及 320 宽双倍字号和 300 高键盘 inset。
- 双端隔离构建验证原生编译。真实 Key、真机安全存储、真实底图、授权与 CRS 另行验收。
