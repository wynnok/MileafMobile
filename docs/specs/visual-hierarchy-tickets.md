| 票据 | 波次／依赖 | 写入归属 | 交付 |

| VH-T00 基线 | W0 | 本轮实施记录的基线段，测试和源码只读 | 固定实际基线提交及纳入的在途切片，基线分析、测试、底栏局部图、四根页图和页面入口矩阵。列出由其他会话在改的文件与测试 |

## 2 通用开场

把这段和下面对应的专用段一起粘贴到新会话，附协调会话给出的基线和依赖交接。

```text
在 MileafMobile 按 VH 规格实施当前票据。先读 AGENTS.md、docs/adr/0018-visual-hierarchy.md、docs/specs/visual-hierarchy.md 的相关条款，以及 visual-hierarchy-tickets.md 的文件归属。以协调会话给的提交与已纳入切片作为基线，先记 git status --short，发现共享文件有在途修改时把冲突交给持有者。
只迁移设计理念，使用行笺现有任务流、样式和文案。底部 Tab Bar 的子树、样式、动效、默认材质分支与 tokens 原样保留。保持入口、请求、车辆／期间、精度、读屏和业务权限。用 tool/flutterw 跑切片验证，截图写 build/<切片>-renders，交接报告列出变更、实测、样张路径、失败和待外部验证项。提交、推送、部署和 GitHub 操作分别按当次授权执行。
```

## 3 票据专用提示词

### VH-T00 基线

```text
登记本地 HEAD、工作区在途切片、目标入口与样张夹具。已知在途的读数第三行、能耗密集温度组、全部指标和专题间距需确认如何并入。复用 chromatic_intensity_render_test 和 liquid_glass_nav_render_test 的夹具，固定截图屏宽、倍率、安全区、字体、主题、偏好和正常／异常数据条件。分别记已有告警、测试和实际首屏预算。分配所有共享源码／测试持有者，交付基线、夹具、冲突表和 W1 任务输入。
```

### VH-T01 颜色、卡片和读数

```text
实现 VH01–VH04、VH09。复用六个亮面原料，新增两类背板的取色角色并成对解析主副前景；保留普通 tint，保护 0 与 null。提供同卡头色面和中性图区的组件接口，保留已有图头第三行、主线、柱、步进与读屏。覆盖两主题全部域、普通底、焦点、入口、选中与切换时配对。输出可粘贴的构造示例和实际 token／前景 API，注明由 T02 使用的玻璃角色；改图表共享文件前核对在途工作。
```

### VH-T02 非底栏玻璃

```text
实现 VH10–VH12 的非底栏材质：根／二级顶栏滚动合成、下拉／二级更多两个菜单和地图浮控。适配黑白、高亮和文字纹理底，高对比和减少透明度走同几何实色，原生底图使用待验证回退。每个新增区域只有一层有界滤镜，检查暗底、焦点和菜单关闭后的回焦。用原底栏渲染夹具证明结构、样式、偏好回退与动效一致。记录平台图层验证留项。
```

### VH-T03 按钮、编排和状态

```text
按 VH05–VH08、VH12 校准按钮字形和命中、状态视图、披露和弹层。先核对 ChipRow 的工作区密集温度组与多行修复。给出 320／200% 和键盘内滚的证据，复用既有 M01–M12 定时和减少动态效果。给页面包交接图标映射、状态选择规则和几何 token；与 T02 分开处理菜单和其它弹层。
```

### VH-T04 概览和行程

```text
实施 P01、P02、P04，按 §5 将里程或行程关键值区接入主焦点取色，保持概览范围与读数第三行，行程节奏图仍在记录之后。验证同一车辆／期间从概览或行程进入详情，再返回原焦点和滚动位置。测试空结果、缓存、地图速写、无采样与首屏 80/64dp 绘图区。按 T08 的验收清单处理同文件的 MetaPage 样式接线并交其验收。
```

### VH-T05 充电

```text
实施 P03、P05、P14。费用已记录时以 cost 色面集中账目，充电详情以实际电量域取色，记录与曲线可就地核对。保留 0、无费用、无币种、充电中、无采样的状态区分。验证地点地图缺坐标／瓦片失败后仍可读 SOC 与功率。逐个验证费用预检、403、409、关闭锁定及待确认恢复，核对输入不丢失、请求与原行为相同。出浅深、首屏、大字键盘和异常样张。
```

### VH-T06 统计根和索引

```text
实施 P06 与 P15 的统计索引部分。保留同视图读数、图、主题入口、全部指标，给趋势中性绘图区，长期入口维持中性。浅色专题 32%，深色 24%，核对四个色相上限。复测专题首行、200% 单列、索引页 8/32dp、原始指标和深链携带同车同期间。工作区的原有布局修复和术语守卫继续生效。
```

### VH-T07 统计专题和证据

```text
按分配实施 T07a 或 T07b，依据 P07–P11 与 P15 的证据列表。按各自实值赋域，保持样本、单位、归因限制及选择。T07a 验证 13 温度组、≤6／>6 选项方式、零与未知、日历与选日返回。T07b 验证补能费用覆盖、6／12 月带、停放正负和状态明细，并区分同节 12dp 与独立节 32dp。保留现有下钻与状态，交付对应页面的双主题、窄屏和关键异常图。
```

### VH-T08 设置、会话和工作区

```text
实施 P12、P13、P16 的中性配置与会话任务。检查连接、登录、初始化、连接管理、HTTP 信任、地图 Key、币种、外观、服务信息和车辆选择。对带键盘、高对比和减少透明度等偏好做回归，保留权限、凭据保护和原确认。向 T04 提交 MetaPage 的验收要求并核查最终入口。工作区仅接当前车辆和弹层，底栏沿旧实现。
```

### VH-T09 汇合与验收

```text
核对前置整合提交、文件责任归属与 VH01–VH14 覆盖。用同夹具生成四根页浅深前后图，登记有效视口、高彩面积、焦点色面彩度与首屏几何；余下 P01–P16 逐入口用 AQ 矩阵走查。带主题和偏好测底栏、两类弹出菜单、原生地图回退、320／200%、键盘、离线、恢复、失败和补录。运行分析、格式、全量测试、文案守卫和独立双轴审查，将待修返回持有者。同步三份索引、实施记录和历史，外部 #11／#16／#17 按各自证据报告。
```
