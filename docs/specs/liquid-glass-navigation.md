# 液态玻璃底栏规格（L01–L12）

> 2026-11-16 接续说明：[Apple 质感精修规格](apple-polish.md)（当日已确认）的 PD05 修订 L09，底栏标签放大封顶 1.35× 并以长按大内容查看器补足；L01–L08 不变，在 AP02 实施并验收前 L09 继续有效。
>
> 2026-11-18 修订：用户以截屏红框指出「再透明一点，透明到能够隐约看到 tab bar 后面的内容，再靠近 iOS 27 的液态玻璃一点」。L03 的未选文字、L04 的实测值与 §3 的 token 表按新材质重定，并新增 L10–L12；L01、L02、L05–L09 不变。

状态：已落地（2026-11-16，2026-11-18 修订），决定见 [ADR 0013](../adr/0013-liquid-glass-navigation.md)。本规格是[焕新规格](apple-design-renewal.md) R14–R15 的增量，只覆盖根级悬浮底栏；顶栏材质、目的地与顺序、阅读连续性、控件几何不变。

## 1 目标与边界

1. 悬浮底栏读起来是**玻璃**：背后的内容要看得见走向与颜色（浅色叠色总量压到标签带 ≤32%），但读不出字；标签与图标在应用内中性底（canvas / surface）与品牌色透出时清楚。越过这个边界的底（照片、地图底图）不保证 4.5:1，按 R14 走实色。
2. 材质是静态光学：没有扫光、没有随滚动的光学变化，同一屏内材质恒定，只有位置随内容变化。
3. 系统信号（高对比、减少透明度）与宿主传入的模态覆盖都落到同几何实色，视觉降级但位置标记保留。`forceSolid` 由宿主判定并传入：根壳以 `ModalRoute.isCurrent` 驱动，`MileafNavBar` 自身不查路由。
4. 不引入平台视图、不改变地图接入方式；原生 Liquid Glass 的折射与系统材质联动仍在 ADR0012 的原生候选里。

## 2 条款

| 编号 | 条款 | 判据 |
| --- | --- | --- |
| **L01** | 每 route 仍只有有界 blur：玻璃路径恰好一层 `BackdropFilter`；高对比、未知或已请求减少透明度、`forceSolid` 时为 0 层 | `liquid_glass_nav_test` L01 |
| **L02** | 玻璃本身是胶囊：外距 16、下距安全区 8、最小高 64、封顶宽 528 并居中；模糊按实际圆角裁剪 | L02（含 768 宽机位）、`geometry.json` |
| **L03** | 选中镜片是同一胶囊内的第二层玻璃，镜片与底栏使用同一实色判定，不出现「实底浮玻璃」；未选目的地用 `navigationLabel`（浅 #3A444E / 深 #C9D3DD，玻璃变薄后的底栏专用色），选中文字与选中图标都用 `accentStrong`（`accent` 在亮镜片上只剩 3.0:1） | L03、L12 |
| **L04** | 高透不损阅读：标签 ≥4.5:1、选中图标 ≥3:1。渲染口径在 390×844 机位上直接量取标签与图标像素并断言（`contrast.json`）——该入口是 opt-in 的（要传输出目录与字体路径），全量 `tool/flutterw test` 里计作 skipped；墨水/背景各取对自己最有利的分位，量到的是**上界估计**。token 口径另在标签带（0.72）上叠「填充 + 弯月」作同向检查 | L04（token 合成）+ `liquid_glass_nav_render_test` 的像素断言 + L04 |
| **L05** | 镜片位移 180ms easeOutCubic，起步横向 1.06（`glassLensStretch`）后回落；首帧不播、减动效时长归零且不过冲 | L05 |
| **L06** | 玻璃只叠本模式中性色，下沿比上沿更浓（弯月），受光顶边比底边更亮；浅色内缘收暗、深色内缘提亮 | L06 |
| **L07** | 阴影由挖孔 painter 承担：栏影只落在胶囊外，镜片暗晕只落在镜片外；玻璃身下不出现 decoration 阴影，栏内不被透出灰带 | L07（结构）+ 实施记录 §3.2（迭代事实） |
| **L08** | 实色路径的镜片用 `navigationSelection`（浅 #E6E9ED / 深 #343C46）并与玻璃镜片同几何，选中不只剩颜色 | L08 |
| **L09** | 320 宽 + 200% 字号下仍是完整胶囊：高度按实际文字增高、四个标签不截断、镜片不越界 | L09 |
| **L10** | 透光率有区间：玻璃体在标签带（相对高度 0.72）的总叠色 浅 18–32%、深 48–52%，顶边仍保留受光带（≥20%）。深色区间比浅色更窄也更靠上——深色玻璃压在品牌蓝图表上时只有把合成压到 L≈0.05 才够 4.5:1（28%→44% 时实测 4.24，现 29%→45% 为 4.92），所以深色的**下限**由 L04 决定，上限只剩 1.3pp 余量 | L10 |
| **L11** | 受光带与弯月真的接到画布上：`sheenReach`、`sheenCore`、`meniscusStart`、`lipReach` 必须来自 `MileafMaterialMetrics` 且非退化值（历史上它们停在默认 0 / 1 / 0，等于画了看不见的带） | L11 |
| **L12** | 镜片是第二层玻璃：自带受光带（`glassLensSheen`，reach 0.5）、顶边亮度高于底边、填充与底栏不同色；未选图形用 `navigationLabel`。受光带只在底栏镜片打开（`MileafGlassLens(sheen: true)`），顶栏的车辆胶囊与设置圆钮沿用 R14 取值 | L12 + `apple_polish_ap02_test`「顶栏镜片不带底栏的受光带」 |

## 3 token 差异（R14 要求的登记）

R14 规定材质 token 的调整必须登记。下表即本次登记：最上排为 R14 初始值，中间为 2026-11-16 液态玻璃首版，最下为 2026-11-18 现值。顶栏未采用本表，仍按 R14 的 18σ / 0.88–0.90 叠色。

| 参数 | R14 初始（顶栏沿用） | 首版（11-16） | 现值（11-18，浅 / 深） |
| --- | --- | --- | --- |
| 背景模糊 | 18σ | 36σ | 22σ |
| 过饱和 | 无 | 1.35 | 1.5 |
| 玻璃体叠色（上 → 下） | surface 0.88 / 0.90 单层 | 白 40% → 56% / 10,11,13 48% → 63% | 白 12% → 20% / 10,11,13 29% → 45% |
| 顶部受光带 | 白 0.35 / 0.10，1 物理像素 | 白 55% / 14%，覆盖到 52% 高度（**未接线**） | 白 25% / 12%，0–16% 为镜面线、到 55% 散尽（已接线） |
| 下沿弯月 | 无 | 白 18% / 黑 35%，自 58% 高度起（**未接线**） | 白 8% / 黑 30%，自 58% 高度起（已接线） |
| 端头增厚 | 无 | 无 | 石墨 6% / 白 10%，只压左右 8.5% 宽度 |
| 受光边缘（顶 / 侧 / 底） | text 0.10–0.14，1 物理像素 | 白 90% / 32% / 26%；深 35% / 16% / 10% | 白 95% / 石墨 14% / 石墨 20%；深 35% / 16% / 10%（竖向着色：顶亮、双侧衰减、底最暗） |
| 内缘细线 | 无 | 石墨 12%（浅）/ 白 12%（深），只压下半圈 | 石墨 17%（浅）/ 白 12%（深），只压下半圈 |
| 外阴影 | text 0.10 Y4 b16 / 黑 0.28 Y4 b16 | Y10 b28 s-6 + Y2 b6 s-2，挖孔绘制 | 不变 |
| 选中底 | segmentSelected 实色 | 第二层玻璃（白 55%→40% / 白 15%→10%）+ 自身受光边 | 白 55%→40% + 白 40% 受光带 / 白 8%→5% + 白 10% 受光带 |
| 选中底几何 | R15「距外框 4」 | 侧 4 / 上下 6（沿用现有实现，未随本次改动） | 不变 |
| 半径 | R14/R15 的 28 圆角矩形 | 胶囊（取高度一半） | 不变 |
| 未选目的地 | — | `textMuted` | `navigationLabel`（浅 #3A444E / 深 #C9D3DD） |
| 选中图形 | — | `accent` | `accentStrong`（与文字同强度） |

未选目的地使用 `navigationLabel`（原 `textMuted`，见 ADR 0013 §「2026-11-18 修订」），选中使用 `accentStrong`（文字与图标）。

## 4 验收与外部 gate

- 代码与自动化：`tool/flutterw analyze` 无诊断；`tool/flutterw test` 中本规格相关的 `liquid_glass_nav_test`（L01–L12）与 `apple_polish_ap02_test` 的顶栏镜片用例全绿。渲染机位是 opt-in 入口（需 `--dart-define` 指定输出目录与字体），按 §4 的命令单独跑。
- 图证：`docs/implementation/liquid-glass-nav-renders/`（390×844、DPR 2、100% 字号、safe area 24/24、Asia/Shanghai），`contrast.json` 为同一次运行的像素测量结果。
- 真机材质观感、系统「减少透明度 / 提高对比度」的真实映射、滚动时的合成帧成本，分别沿 #11 / #16 / #17 验收，本规格不关闭它们。
